# Биомы: разделение и пересечения

**Статус: ЧЕРНОВИК ДИЗАЙНА.** Из общих законов реализованы 30.09.2026 только лесные: выстрел лучника по всем на линии, толчок кабана, шипы по краю и колючки ([GDD](../gdd.md), раздел 5). Остальное — план. Решение пользователя от 29.09.2026: противники строго разделены по биомам. Ростеры:
- [лес](forest-roster.md);
- [замок](castle-roster.md).

Реализованное поведение описано в [GDD](../gdd.md).

## Правило разделения

1. **Каждый враг принадлежит ровно одному биому.** Враг не переходит в другой биом под новым обликом с тем же поведением.
2. **Общие законы мира одинаковы везде.**
   - Удар получает тот, кто стоит на поражённой клетке, — кот или враг.
   - Толчок сдвигает существ. Вытолкнутый на смертельную местность враг погибает, освобождая место. Кот получает урон, а в открытом провале погибает, как сейчас.
   - Заморозка выключает главную особенность врага.
   - Убийства чужими атаками засчитываются игроку.
   - Всё объявлено заранее, прогноз совпадает с исполнением.

   Законы не принадлежат биомам: игрок не должен переучивать физику.
3. **Одна идея — свой «диалект» в каждом биоме.** Если идея нужна обоим биомам, она по-разному выражает их темы:
   - лес: **REACT TO CREATURES** — хаос, живые существа, пробивание;
   - замок: **READ AND MANIPULATE THE BOARD** — геометрия, блокирование, поле как механизм.
4. **Устройства карты тоже принадлежат биому.**
   - Лес: рычаг стрел, жаровня, провалы.
   - Замок: бочка, живая дверь.
5. **Предметы, способности и огонёк общие.** Это инструменты кота, а не противники.

## Диалекты общих идей

| Идея | Лес | Замок | Чем различаются для игрока |
| --- | --- | --- | --- |
| **Выстрел** | Лучник: **объявленная полоса до 3 клеток**, тела не прикрывают, бьёт всех на полосе | Ладья, слон, королева, картина: **по линии до первого тела**, это тело получает удар | Лес — «не стой там, куда целятся». Замок — «прячься за телами и подставляй первого» |
| **Толчок** | Кабан таранит по вертикали или горизонтали: бьёт первого и **расталкивает весь ряд**; пустоты от цепи поглощают толчок; кто не влез — на шипы | Кресло сдвигает **одно** существо на одну клетку | Лес — массовый хаос, которым управляют пустотами. Замок — точечная перестановка по правилу |
| **Снаряд игрока** | Рычаг стрел: залп по линии, бьёт всех (устройство) | Бочка: катится, давит слабых, останавливается на первом крепком | Оба запускает цепь игрока. Лес — залп, замок — «боулинг» |
| **Опасная местность** | Шипы по краю поля (вытолкнутый враг гибнет); колючие клетки внутри поля (1 урон); открытые провалы | Очаг / кипяток котла | Куда вдавливать врагов толчком |
| **«Игнорируешь — станет хуже»** | Шаман: по **времени**, пока жив источник | Пешка: по **позиции**, превращение на последней линии | Против шамана — «убей источник». Против пешки — «не дай дойти» |
| **Поддержка** | Шаман усиливает | Король защищает соседей (цель боя). Книга меняет правило фигуры | Лес — рост цифр. Замок — изменение правил и строй |
| **Изменение местности** | Паутина: временная, органическая, обрывает цепь | Шкаф падает и становится **постоянной** стеной. Дверь открывается и закрывается **по ритму** | Лес сужает маршрут. Замок перестраивает поле навсегда или по расписанию |
| **Опасные клетки** | Провалы: устройство игрока. Лягушка убрана | Котёл: вражеский разлив на 1–2 хода | Лес — игрок решает, когда открыть. Замок — читает, когда и где разольётся |
| **Направленная защита** | Щитоносец, Тюремщик: щит | Нет щитов. Защита — стены, тела на линиях, аура короля | Щит — лесная механика. В замке «прикрыться» значит поставить тело или стену |
| **Взрыв** | Сапёр: при гибели бьёт соседей | Нет | — |
| **Дальний залп по клеткам** | Нет | Рой приборов (кухня): живое воплощение залпа ворот | — |
| **Прыжок через преграды** | Прыжок кота (общий) | Конь: враг, для которого преграды не защита | — |
| **Анти-цепь** | Дикобраз | Нет прямого аналога; роль длинной цепи ограничивает геометрия | — |

## Пересечения внутри присланных списков

Выявлены при разборе. Решения — в документах биомов.

- **Кабан × ладья с рывком × бочка** — три «тарана». Решение:
  - кабан — лесной толчок, который расталкивает ряд;
  - ладья остаётся турелью с блокируемыми линиями, как сейчас в движке;
  - бочка — снаряд, который запускает игрок.
- **Шаман × книга × король × пешка с превращением** — четыре «усилителя». Разведены по оси: время, правило, строй, позиция.
- **Щитоносец × шахматный страж × шкаф-защитник × страж-щит** — щит остаётся только в лесу. Шахматный страж не нужен. Правило шкафа (−1 урона соседу) переходит в ауру короля.
- **Шкаф × стол** — оба «враг становится стеной». Стол убран, шкаф остаётся.
- **Дверь × шкаф × паутина** — все меняют геометрию. Оставлены с разными осями:
  - дверь — ритм;
  - шкаф — навсегда;
  - паутина — органическая и временная.
- **Котёл × лягушка × провалы** — лягушка убрана, котёл — вражеский разлив, провалы — устройство игрока.
- **Рой приборов × лучник** — если рой стреляет по линии, это копия лучника. Решение: рой бьёт по объявленным **клеткам**, как залп со стены.
- **Зеркало × колдун** — копирование действий игрока слишком сложно для рядового врага. Переносится в механику босса.

## Уже реализованные враги: куда они относятся

Сейчас враги частично перемешаны. Страж-щит и тяжёлый страж живут в замке, Тюремщик — в лесу. Предлагаемое распределение (миграция — отдельная задача после согласования):

| Реализовано | Сейчас | Предложение |
| --- | --- | --- |
| Гоблин (`melee`) | Лес, ворота, уроки | Лес: воин-гоблин |
| Лучник (`ranged`) | Лес, уроки | Лес: лучник без изменения геометрии (линия до 3 клеток, тела не прикрывают). Удар получают и враги на объявленных клетках — **реализовано 30.09.2026** |
| Главарь (`boss`) | Лес | Лес: босс (или Тролль) |
| Тюремщик, колокол | Уроки 14–16 | Лес: Тюремщик — босс гоблинского акта. Колокол — заменить шаманом или оставить устройством |
| Страж-щит (`sentinel`) | Караульная, библиотека | **Перенести в лес** как гоблина-щитоносца. Из замка убрать |
| Тяжёлый страж (`elite`) | Караульная, библиотека | **Удалить**: отличается только HP |
| Стул, табурет | Залы, башня | Замок: наполнение (стул) и вооружённое наполнение (табурет) |
| Шкаф-защитник (`cabinet`) | Пир, библиотека, башня | Правило защиты соседа → **аура короля**. Отдельный враг не нужен |
| Гардероб 2×2 (`wardrobe`) | Пир | Замок: **злой шкаф**, падает и становится стеной |
| Ладья, слон, конь | Шахматный зал, библиотека | Замок: основа шахмат. Добавить «первое тело получает удар» |
| Командир / хранитель ключа | Ворота, залы | Замок: **король** — хранитель ключа и цель строя |
| Колдун | Башня | Замок: финальный босс |
| Залп со стены | Ворота | Замок: вход в биом. Родственник роя приборов |
| Рычаг стрел, жаровня, провалы | Уроки | Лес |
| Огонёк | Уроки, поход, редактор | Общий |

Караульная полностью строится на удаляемых или переносимых врагах (тяжёлый страж и страж-щит). Её тему нужно заменить, например, жилыми покоями с мебелью.
