=== ЗАДАЧА 20 «Телеметрия: ресурсы и выход из круга» (телеметрия core) ===
Только запись и отчёт, правила и хэш мира не меняются.
- RunRecord: ресурсы на старте похода; получено по источникам (котомка, события, сундуки, торговец, подвиги, прочее); потрачено по стокам (крафт, лечение на карте, торговец, прочее); остаток в конце. Сумма сходится: старт + получено − потрачено = остаток.
- Запись боя, на каждый перебор (`slotBustArea`): расстояние героя до идола при «lit»; был ли в круге; через сколько вышел (или не вышел); чем вышел — ходьба / проход цепи / прыжок / остался в круге, но неуязвим; урон.
- Отчёт `npm run realtime:report`: раздел «Ресурсы похода» (старт, по источникам, по стокам, остаток); в разделе гоблина — «выход из круга» (медиана времени, способы).
- Старые записи — «—», не ошибка.
Приёмка: Node — запись похода с котомкой и крафтом даёт сходящийся баланс; бой с перебором даёт время и способ выхода, совпадающие с переигрыванием журнала; старая запись читается.
