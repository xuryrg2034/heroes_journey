## 3. А. Смолокур

### 3.1. Вид

| Поле | Значение |
| --- | --- |
| Имя | «Смолокур» (строка «Сразил»: «смолокур» — касание; «горшок смолокура» — удар горшка) |
| id | `pitcher` (grep 17.10.2026: свободно) |
| HP | 1 (`hp: () => 1`, не бросок крепкого) |
| Пластины | 0; никогда не элита (`noElite`, нет в `GARRISON_ELITE_KINDS`) |
| Размер | тело 1, рисунок 1 (как стражник) |
| Скорость | класс `slow` |
| Цвет | цвет палитры, обычное звено цепи |
| Касание | как у обычного (`contactDamage`) |
| Дистанция | держится в `pitchNear` 4 … `pitchFar` 7 от героя: ближе — отходит, дальше — подходит (как Арбалетчик) |

### 3.2. Цикл

1. **Готов** — перезарядка кончилась, общий таймер разрешает (3.4), герой не ближе 2,5 ед. и не дальше `pitchFar` + 1. Прямая видимость **не нужна**: горшок летит навесом через ящики и частокол. Это главное отличие от Арбалетчика: за ящиком не спрячешься — уйди с метки.
2. **Замах** `pitchWindup` 0,6 с. Смолокур стоит, горшок поднят над головой и дымит. Знак на смолокуре, метки ещё нет.
3. **Бросок.** Точка цели — центр героя **в момент броска** (конец замаха). Точка фиксируется и не следит за героем. Горшок летит `pitchFlight` 1,2 с по дуге (первый бросок в бою — ×1,5 = 1,8 с). Всё время полёта на земле мигает метка радиуса `pitchRadius` 0,7 (вспышка раз в 0,12 с, как `GrenadeBullet` CotL).
4. **Падение.** Тело героя касается круга метки (центры ближе 0,7 + 0,28) — `pitchDamage` 1. Врагов горшок не ранит. На месте падения — лужа смолы (3.3).
5. **Перезарядка** `pitchReload` 5 с.

- Замороженный смолокур ждёт (таймеры стоят). Горшок в полёте долетает.
- Смерть смолокура в замахе снимает бросок. Горшок в полёте долетает.
- Проход и прыжок защищают (неуязвимость движения). Щит цепи, «Щит фокуса», неуязвимость после удара гасят удар (`canBeHurt`, событие `block`). От лужи щиты не спасают: лужа — местность.
- Проход горшок не гасит и не берёт в цепь (тяжёлый снаряд, отчёт CotL, E.2 п. 3). «Магическое оружие» на него не действует: смола — не магия.
- Горшок, упавший в воду или над обрывом, лужи не даёт (как точки огня `hammers.ts`).

### 3.3. Лужа смолы (закон смолы)

| Поле | Значение |
| --- | --- |
| Радиус | `pitchPoolRadius` 1,0 (чуть шире метки) |
| Жизнь | `pitchLife` 4 с, затем высыхает |
| Герой | ходьба ×`pitchHeroSlow` 0,6, пока центр героя в луже. Складывается с толпой (×0,7) и не складывается с водой (в воде лужи нет) |
| Враги | ходьба ×`pitchEnemySlow` 0,4, пока центр врага в луже: обычные, стражники, псы на поводке и в ярости, сам смолокур. Поле потока лужу не обходит: враги в неё входят |
| Не действует | на проход героя, прыжок, рывки врагов (рывок рыцаря, «Спустить пса»), неподвижных (узник, ядро босса), отброс |
| Предел | не больше 4 луж на арене (`PITCH_MAX`, константа модуля); пятая сушит самую старую |
| Перекрытие | две лужи в одной точке не складываются |

Ответ игрока: уйти с метки; не стоять в смоле; **использовать смолу**: толпа в луже стоит кучей — готовая цепь. Кинуть горшок в толпу — заманить смолокура метить героя у толпы.

### 3.4. Общий таймер смолокуров

По отчёту CotL (`EnemyArcher.GlobalShotDelay`, раздел G.1, п. 1):
- Замах нового броска любого смолокура начинается не раньше `pitchGap` 2,5 с после прошлого броска любого смолокура арены. В воздухе — не больше одного горшка.
- Пока Арбалетчик арены целится (`crossbowLine` не пуст), замах горшка не начинается. Правило читает состояние арбалета и не меняет его: журналы без смолокура не меняются. **[Д]** вопрос В6 — рекомендация «да»: одна угроза по времени за раз.

### 3.5. Смола и огонь

Смолу поджигает **только огонь героя**:
- точка огня «Огненного прохода» (и сплава «Клеймо»: тот же путь) касается лужи;
- горящий враг (расходник «Огонь», `Enemy.burn`) стоит центром в луже.

Не поджигает: огненный след элиты «Огненный», жаровня, взрыв. Причина: один источник — одно правило. Огонь врага ранит героя, огонь героя — нет; смола, зажжённая врагом, ломала бы это.

Горящая лужа:
- горит `pitchBurn` 2 с, затем исчезает (смола выгорела);
- враг, центр которого в луже: −1 при входе, затем пауза 1 с (числа `FIRE_DAMAGE`, `FIRE_PAUSE` молота: тот же огонь);
- убийства — игрока (`credited`, источник `pitch-fire`): счётчик, цель «убей N», котомка; не убийства цепи (без комбо и щита), как огонь молота;
- героя не ранит никогда (правило огня молота);
- замедление горящей лужи прежнее: враги вязнут и горят.

Это сочетание «смола + огонь» — находка сборки для повадки «Пламя».

**Подсветка = исполнение.** Поджог проходом — после конца прохода (правило гарнизона: состояние меняется после прохода).
- `planChain(...).fire` знает, загорится ли путь (порог `fireMinLinks`, задача 31). Если загорится, план даёт список луж, которые путь пересекает (`fire.pitch`: id луж).
- Отпускание фиксирует список (`HeroMove.pitch`, образец `HeroMove.cuts`). Лужа из списка не высыхает до конца прохода. После конца прохода загораются ровно лужи списка.
- Вид: при выделении цепи лужи списка — с огненным краем (тот же знак, что путь с огнём).
- Поджог горящим врагом — в такт, когда центр горящего врага в луже (не во время прохода: ждёт конца).

### 3.6. Проверка окна

Правило 7б: окно ≥ 0,2 с + выход из худшей точки / 4 ед/с. Худшая точка — центр метки.

| Угроза | Окно | Выход | Нужно | Итог |
| --- | --- | --- | --- | --- |
| Горшок, первый в бою | 1,8 с | (0,7 + 0,28) / 4 = 0,245 с | 0,445 с | ✓ |
| Горшок | 1,2 с | 0,245 с | 0,445 с | ✓ |
| Горшок, герой в смоле и толпе (×0,6 × 0,7 = ×0,42; 1,68 ед/с) | 1,2 с | 0,98 / 1,68 = 0,58 с | 0,78 с | ✓ |
| Болт, герой в смоле и толпе | 1,0 с | 0,53 / 1,68 = 0,32 с | 0,52 с | ✓ |
| «Размах» рыцаря, герой в смоле и толпе | 0,8 с | от края тела: (1,6 + 0,28 − 0,6) / 1,68 = 0,76 с | 0,96 с | **✗** |

Вывод: **смолокур и «Размах» (рыцарь в наступлении, привратник в гневе) не стоят в одном бою.** Правило для level-designer и проверка в `telegraphWindow.spec.ts` (запись «смолокур: горшок» и запись запрета сочетания). Фокус замедляет и героя, и горшок — отношение то же.

## 4. Б. Новобранцы

### 4.1. Вид

| Поле | Значение |
| --- | --- |
| Имя | «Новобранец», группа — «новобранцы» (строка «Сразил»: «новобранец») |
| id | `recruit` (свободно) |
| HP | 0 (всегда слабый; `hp: () => 0`, не бросок крепкого) |
| Пластины | 0; никогда не элита |
| Размер | тело 1, рисунок 0,9 (молодой, мельче стражника) |
| Скорость | класс `slow`, ходит строем стражи (`guardFormation`, шаг 0,9) |
| Группа | 4 одного цвета (стартовый строй или доля притока `group: 4`) |
| Касание | как у обычного |
| Номер | 1–4 над головой, всегда виден (знак тела, как пластины рыцаря) |

### 4.2. Закон порядка

- **Текущий номер** группы — наименьший номер живого новобранца.
- **Цепь берёт только текущий номер.** Новобранец не по порядку — не кандидат: кольца нет, у курсора отказ «не по порядку» (код `order`, `REFUSAL_TEXT`). Нажатие на него цепь не начинает.
- **Очередь сдвигается внутри прохода.** В рисуемой цепи новобранец №1 уже звено → №2 становится текущим для следующего звена. HP 0 — каждое звено-новобранец гибнет (пластин нет, сила ≥ 1), поэтому план прост: номер следующего = 1 + число новобранцев группы в цепи и мёртвых.
- **Звено погибло, пока цепь рисуется** (например, бомбой текущего): выпадает из цепи по общему правилу; очередь пересчитывается по живым; звенья цепи после него, которые стали «не по порядку», выпадают (подсветка показывает это так же, как сделает проход; образец — решётка Кастеляна).
- **Номера пришли, пока цепь рисуется** (строй неполный ждёт 1 с, номера раздаются позже): цепь читается от начала, звено-новобранец остаётся, если его номер — текущий для группы с учётом оставленных раньше звеньев; иначе выпадает **только это звено**, остальные звенья остаются (как при гибели звена, досягаемость не перепроверяется; не срез, как у решётки). Группы считаются отдельно. Выпадение — не удар: события `recruit refused` нет. Пока идёт проход (`world.move`), номера не раздаются. Подсветка показывает выпадение так же, как сделает проход (решение дизайна 21.10.2026, вариант А core).
- **Не по порядку их не ранит ничто:** ни цепь, ни бомба, ни огонь (расходник, молот, смола), ни болт, ни укус пса и узника, ни «Размах», ни волна, ни взрыв на конце, ни «Печать», ни «Прямая», ни «Возврат», ни «Режущий проход». Удар доходит и гаснет (событие `recruit` `refused` у новобранца, без урона; вид рисует ту же искру, что у блока. Не `block`: это имя уже значит «удар по герою погашен» — правка 21.10.2026 по вопросу core). Тело остаётся телом: болт на нём останавливается, отброс его двигает. Для толчка вещи замка (55а) новобранец не по порядку — упор: толчок его не давит.
- **Удар по многим сразу** (волна, взрыв, «Печать», «Режущий проход», «Возврат»): тела группы бьются **по возрастанию номера**, очередь сдвигается после каждого убийства. Кольцо «Печати» вокруг всего строя убивает строй целиком — награда редкой формы **[Д]**, вопрос В8.
- **Весь строй одним проходом:** если все новобранцы группы гибнут от ударов одного прохода (цепь, её «Прямая», «Возврат», волна и взрыв на конце, кольцо «Печати» и «Режущий проход» этого прохода; новобранец, добитый по порядку чужим источником — болт, горение, бомба, — строй этого прохода не завершает), герой получает `recruitBonus` 2 энергии (не выше `ENERGY_MAX` 7) после конца прохода. Строй, начатый раньше (№1 убит прошлой цепью), бонуса не даёт.
- Новобранцы не цель Ключника (список `SHACKLE_KINDS` прежний).

Почему отказ, а не «выживший кончает цепь» (вариант CotL): главная открытая жалоба — контроль цепи («выбираю не то»). Отказ у курсора не наказывает за промах мыши, а учит читать номер. Варианты — вопрос В2 **[П]**.

### 4.3. Номера

- Номера раздаются при появлении строя потоком `behavior:recruit` по месту в строю.
- **Ограничение пути:** соседние номера стоят в строю не дальше двух мест (≤ 1,8 ед. при шаге 0,9). Тогда цепь 1 → 2 → 3 → 4 всегда возможна: досягаемость R до края тела = 1,875 + 0,36 = 2,235 > 1,8, а три места (2,7) уже нет.
- Порядок «по линии» (1-2-3-4 и 4-3-2-1) исключён: строй требует маршрута, а не ближайшего тела. Остаются перестановки вида 1-3-2-4, 2-1-3-4… (core проверяет `planChain` на каждом seed, что путь 1 → 4 в одну цепь есть).
- Строй разворачивается при ходьбе (места по стороне пути, `formLines`), поэтому рисунок номеров со стороны героя меняется.
- На арене не больше 2 строёв новобранцев одновременно, разных цветов. Номер рисуется цветом группы. Предел держит ядро под ключом `recruits` (предел притока, как `boarMax`): приток третий строй не даёт.

### 4.4. Угроза

Своей атаки нет: касание, как у стражника. Давление — живая стена из 4 тел, которую нельзя срезать ближайшим телом, взрывом или огнём. Окно телеграфа не нужно (касание без телеграфа — список 7б).

### 5.2. Закон пары

- **Оба одним проходом** — гнева нет. Это цель игрока.
- **Погиб один, второй жив после конца прохода** — второй в **гневе** `wardenAnger` 8 с. Смерть вне прохода (бомба, болт, пёс, огонь) — гнев сразу в такт смерти.
- **Гнев:** класс скорости `fast`, касание 2, приём «Размах» (5.3). Кольцо отсчёта гнева у ног. Через 8 с — снова спокоен (`slow`, касание обычное), но пары у него больше нет.
- Убийства привратников — по общему правилу: засчитываются игроку, если убил игрок.
- **Цвет привратника не меняется**: перекраска («Клеймо», будущий Жрец) его не берёт. Пара двух цветов — закон вида.

### 5.3. «Размах» в гневе

Тот же закон, что «Размах» рыцаря (одно имя — одно значение): круг `knightSwingRadius` 1,6 вокруг привратника, замах `knightSwingWindup` 0,8 с (первый в бою ×1,5 = 1,2 с), герою `knightSwingDamage` 2, врагам в круге по 1 (не в зачёт игроку); удар ждёт конца прохода героя. Пауза между размахами `knightPause` 2 с, первый — через 2 с после начала гнева (окно добить). Числа — ключи рыцаря **[Д]**, вопрос В10: свои ключи разведут закон.

Проверка окна (от края тела, как в задаче 43): (1,6 + 0,28 − 0,6) / 4 = 0,32 с + 0,2 = 0,52 с ≤ 0,8 ✓; в толпе (×0,7) 0,66 с ✓. В смоле — ✗ (3.6): смолокура в бою с привратниками нет.

### 5.4. Как убить обоих одной цепью

| Путь | Как | Чем учит |
| --- | --- | --- |
| «Смена цвета» (поход: 6, свобода держится) | 5 врагов цвета A → привратник A (6-е звено, цвет свободен) → привратник B | главный путь: привратники учат смену цвета |
| Форма «Чужак» | одно звено чужого цвета за цепь — привратник B | находка сборки |
| «Осколок жернова», «Жернов» | смена раньше (5, 4, 3 звена) | находка сборки |
| «Развилка» | следующее звено — у любого звена цепи | помогает маршруту, цвет не снимает |
| Две цепи подряд | вторая цепь в гневе | путь с ценой: «Размах» и касание 2 |

Арена даёт толпу цвета A и строй стражи у пары, чтобы 6 звеньев было из чего собрать (раздел 7).

### 5.5. Подсветка = исполнение

- План знает убийства. Если рисуемая цепь убивает ровно одного из пары (проход дойдёт до него), план даёт `anger: [id напарника]`. Вид рисует на напарнике красное мерцающее кольцо «гнев будет» до отпускания.
- Цепь убивает обоих — у обоих знак пары горит золотом.
- Отпускание фиксирует итог; гнев — после конца прохода.

## 16. Риски

1. **Отказ «не по порядку» и мах мыши.** Протяжка через строй даёт отказы. Проверить, что `sweep` пропускает новобранца не по порядку без обрезки цепи (как тело чужого цвета на свободной цепи, задача 34).
2. **Новобранцы без давления.** HP 0 и касание — их можно бить по одному четырьмя цепями. Давление — только «живая стена». Если плейтест скажет «скучно» — вариант В2 (б) или (в).
3. **Неуязвимость не по порядку против сборки.** Огонь, волна, «Режущий» гаснут на строе — игрок со сборкой «по толпе» может счесть это нечестным. Знак блока обязателен; бестиарий говорит «по номерам».
4. **Гнев и «Размах» в одном бою с толпой.** Касание 2 + быстрый + круг 2 — пик урона. Замер бота; ручка — `wardenAnger`.
5. **Пара без толпы цвета A.** Если приток не даёт 6 звеньев A у пары, путь «одной цепью» пропадает. Перевес цвета A в притоке «Барбакана» и проверка level-designer на seed.
6. **Смола + рывки и «Размах»** (3.6): окно ломается. Запрет сочетания по составу; при нарушении — тест падает.
7. **Смола тормозит поле потока.** Враги копятся в луже — это задумано, но может дать «неподвижный бой» (как первый «Ров»). Предел 4 лужи и жизнь 4 с — ручки.
8. **Набор троп убирает рыцаря из половины походов** (В1) — рыцарь — решение пользователя. Пользователь выбрал (а): риск принят, закрыт.
9. **Общие файлы с 54а и 55** (`chain.ts`, `world.ts`, `params.ts`) — порядок раздела 2.
10. **Имя «смола»** совпадает с ресурсом «Смола» (В4).
