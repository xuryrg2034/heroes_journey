Как читать (как v1):
- Правило выбора не меняется: самый конкретный повод прошлого похода, иначе повтор по кругу; `first` — один раз за профиль; за визит говорят не больше 2 NPC.
- Строки одного ключа идут в порядке показа. Первая — первый раз, дальше — по кругу. Слово «опять» стоит только во второй строке.
- Длина строки — 4–16 слов, не больше двух фраз.
- Места и враги в речи — без кавычек, как в v1 (караульня, Кастелян, Тролль). Названия улучшений, игр и раскладок — в «» («Шишова лавка», «Кости», «Чурбаки»).
- Строки не обещают ничего сверх правил спеки 51 и 49. Чисел, цен и наград, которых нет в спеке, в строках нет.

## Ведунья (задача 49)

Ведунья — герой, не NPC лагеря: улучшений, заданий и ухода у неё нет. Реплики она говорит сама — в клетке, в сцене «Открыть клетку» и у Очага на месте героя.

- **Характер** (спека 49, 6.1, 11). Жаба-колдунья. Надменная, неторопливая, сонно-самодовольная. Благодарить не любит.

### Правила строк v2.1

- 4–16 слов, не больше двух фраз, ё везде, где она есть.

- Имена — из списка «Проверка имён» выше: Неясыть, Марфа, Ерофей, Шиш, Евлампий, Ведунья, Тюремщик, гиря, Ключник, кандалы, узник, караульня, Кастелян, решётка, рычаг, ров, самострел, Тролль, дубина, Последний рубеж, огненный след, лучник, сапёр, колдун, «Кости», круг (у Шиша — только игорный круг, как в его строках v2). ### Заметка для данных (рекомендация core/ui, решают они)

- Строка: `string | { text: string; hero: 'cat' | 'toad' }`. Строка без поля — для любого героя. Списки v1 не переставлять: у кота порядок и счётчики прежние, байт в байт.
- Чей герой: один на визит — герой прошлого похода; без прошлого похода — `meta.hero`. Встреча на привале (`meet_*`) — герой текущего похода.
- Список ключа для героя: строки `hero` этого героя первыми (в порядке таблицы), затем строки без метки; строки с чужой меткой пропускаются. Так у Ведуньи первой звучит её строка без «опять», а «опять» из строк без метки звучит не первой.
- Счётчик: у кота — прежний `npc:key`; у Ведуньи — свой `npc:key:toad`, иначе её первый показ возьмёт номер, накопленный котом. Разовые ключи (`first*`, `win_first`, `win_garrison_first`) считают предел по отфильтрованному списку.
- Пустой после фильтра ключ — повод пропускается и берётся следующий (по решению дизайна: следующая строка без метки, иначе `idle` / `about_*`). С таблицами выше пустых ключей у пяти NPC нет; страховка нужна для `buy_*` (сейчас `line(...)!`).
- Строки Ведуньи (раздел «Ведунья») — отдельный набор героя, метка им не нужна.
