# Задача 45. «Испытание» VI–VIII: ступени, которые требуют лучших цепей

**Статус: спека дизайна, 16.10.2026. Не реализовано.** Основа — отчёт [«Сборки — разнообразие и BALL x PIT»](<reports/Сборки — разнообразие и BALL x PIT.md>) (раздел 5, Н1); лестница «Испытание» I–V — [realtime-slice.md](../realtime-slice.md), «Испытание I–V» (задача 18). Решение пользователя (вопрос с вариантами, 16.10.2026): ступени на навык — **параллельно** со сплавами ([задача 44](task-44-fusions.md)). Все числа — гипотезы для плейтеста.

## 1. Зачем

Ступени I–V — давление на выживание (без зелья, таблицы рядов, неуязвимость и касание, свойства элит, толпа и короткий финал). Лучшая цепь от них не меняется: игрок, который хорошо рисует цепь, проходит их так же. Пользователь пролетает походы. Нужны ступени, где выигрывает **лучший рисунок цепи**, а не запас HP.

## 2. Ступени (накопительно, сверх I–V)

| Ступень | Правило | Что проверяет |
| --- | --- | --- |
| VI | Палитра ряда +1 цвет (ряды 1–2: 2 → 3, 3–4: 3 → 4, с 5: 4 → 5) | Поиск цепи: естественные цепи короче, их надо собирать маршрутом и ждать |
| VII | Фокус ×0,75 (`focusMax` и время замедления) | Скорость рисунка |
| VIII | Враги быстрее на 10 % (`enemySpeed` ×1,1) | Маршрут и выбор момента |

- Открытие — как сейчас: ступень N+1 открывается победой на ступени N.
- Строка ступени под выбором — одна ручка, не больше 6 слов (правило задачи 18): VI «Ещё один цвет на аренах», VII «Фокус короче на четверть», VIII «Враги быстрее на десятую».
- Награда опыта — множитель «Испытания» продолжает расти (как у I–V; число — решение core по прежней формуле).

## 3. Границы (раздел «Границы требований» AGENTS.md)

- Сейчас в игре четыре цвета цепи (`kit.ts` `COLOR_COUNT = 4`, палитра ряда — `rtColorsByRow`). Пятый цвет — новый цвет цепи: в симуляции (палитра, `colorCount` до 5, цветовые правила форм и талисманов) и в виде (тело, кристалл, подсветка, след на карте). Это главный риск задачи. На рядах 1–4 ступень VI работает без пятого цвета, поэтому core может выпустить её в два шага: сначала палитра +1 с пределом 4, потом пятый цвет.
- Лишний цвет меняет генерацию составов. Проверять отдельно: стартовое состояние арены, пополнение (палитра групп, `groupColor`), арены с цветовыми механиками (руны, «Близнецы», Тюремщик, хамелеоны, «Призма», «Смена цвета»). Цвет — из палитры игры, различимый с остальными (проверка ui на снимке).
- Пролог, песочница и ступени 0–V не меняются.
- Цвета, которые несут смысл (радужное кольцо, огненный край, пунктир «Развилки»), пятым цветом не занимать.

## 4. Детерминизм

- Ступень — поле похода `ash` (расширить `RtAshLevel` до 8); поход без поля или с 0–5 — прежний, байт в байт.
- Каждое правило — через ключи `Params`, которые поход ставит по ступени: палитра ряда +1 (новый хэшируемый ключ или поле кита, по образцу `floorScale`/`phaseScale` задачи 18), `focusMax` ×0,75, `enemySpeed` ×1,1; журналы старых походов не меняются.
- Бот: замер «Испытания» VI–VIII на 300 seed (эвристика, с датой) — доля побед бота с прицелом в ядро по ступеням.

## 5. Вид (ui)

- Выбор «Испытание: 0 · I · … · VIII» на «Новом походе», строка ступени, шапка карты — как сейчас.
- Пятый цвет (второй шаг): проверка различимости на снимке 1280×720 (врагов, кристаллов, подсветки цепи).

## 6. Телеметрия

- `RunRecord.ash` 6–8; отчёт «Испытание» — по ступеням, длина цепи (медиана) по ступеням: ожидаем, что VI снижает длину естественных цепей.

## 7. Приёмка

- Node: поход с VI — палитра ряда +1 (старт и пополнение, ряды 1, 3, 5, несколько seed); VII — фокус ×0,75; VIII — скорость ×1,1; ступени накопительны; 0–V и поход без поля — прежние хэши.
- Playwright один раз: выбор VI–VIII, строка ступени.
- Снимки 1280×720: выбор ступени; арена с пятым цветом.
- Доки: `docs/realtime-slice.md` («Испытание»), `docs/realtime-telemetry.md`, README.
- Плейтест: «Пришлось ли лучше рисовать цепь?» — на ступени VI и выше.

## 8. Не входит

Скорость «Быстро» (Н2 отчёта) — пока нет (решение дизайна 16.10.2026: потолок — через навык цепи). Ступени по героям — когда появятся герои.

## 9. Решения дизайна

- **Пятый цвет цепи — mauve `0xa86a9a` (16.10.2026).** Предложение ui с макетом на 1280×720 (песочница, арена 1, цепь из четырёх врагов пятого цвета, толпа, элита пятого цвета, кристалл «Призма» с пятью гранями). Замер ui (CIEDE2000, в обычном зрении и при протанопии, дейтеранопии и тританопии по Machado 2009): худшее расстояние до четырёх цветов цепи — 21,1 / 17,9 / 11,8 / 10,0. У нынешней худшей пары из четырёх цветов — 24,2 / 12,5 / 8,6 / 7,2. До цветов со смыслом (проклятие, магия, подписи, огонь, цель, золото, лёд, лечение) — не меньше 16,5. Тело пятого цвета несёт свой знак (ромб). Plum `0xa0607e` отклонён: на снимке толпы он ближе к красному. Прежний запасной лавандовый `0xb69ad2` (`CHAIN_COLORS[4]`) убрать: при дейтеранопии он сливается с синим.
- «Призма» на пятицветной арене — пять граней. Вид подключается после второго шага core (пятый цвет в симуляции).
