# Задача 45. «Испытание» VI–VIII: ступени, которые требуют лучших цепей

**Статус: спека дизайна, 16.10.2026. Не реализовано.** Основа — отчёт [«Сборки — разнообразие и BALL x PIT»](<reports/Сборки — разнообразие и BALL x PIT.md>) (раздел 5, Н1); лестница «Испытание» I–V — [realtime-slice.md](../realtime-slice.md), «Испытание I–V» (задача 18). Решение пользователя (вопрос с вариантами, 16.10.2026): ступени на навык — **параллельно** со сплавами ([задача 44](task-44-fusions.md)). Все числа — гипотезы для плейтеста.

## 1. Зачем

Ступени I–V — давление на выживание (без зелья, таблицы рядов, неуязвимость и касание, свойства элит, толпа и короткий финал). Лучшая цепь от них не меняется: игрок, который хорошо рисует цепь, проходит их так же. Пользователь пролетает походы. Нужны ступени, где выигрывает **лучший рисунок цепи**, а не запас HP.

## 2. Ступени (накопительно, сверх I–V)

| Ступень | Правило | Что проверяет |
| --- | --- | --- |
| VI | Фокус ×0,75 (`focusMax` — запас замедления в секундах) | Скорость рисунка |
| VII | Ходьба врагов ×1,1 | Маршрут и выбор момента |
| VIII | Пятый цвет цепи на всех рядах (4 → 5) | Поиск цепи: естественные цепи короче, их надо собирать маршрутом и ждать |

- Порядок — по росту трудности: пятый цвет — самый крупный шаг, он последний. Так VI и VII выходят раньше, чем готов вид пятого цвета (решение дизайна 16.10.2026, после вопроса core).
- Открытие — как сейчас: одна победа открывает все ступени (`chooseAsh` проверяет победу). Поступенное открытие — не в этой задаче.
- Строка ступени под выбором — одна ручка, не больше 6 слов (правило задачи 18): VI «Фокус короче на четверть», VII «Враги быстрее на десятую», VIII «Пятый цвет на аренах».
- Опыт — прежняя формула: VI ×1,6, VII ×1,7, VIII ×1,8 (`RT_XP_ASH_STEP` 0,1).
- VI: замедление ×0,25 и восстановление не меняются; множитель складывается с «Тяжёлым клинком»; полоса фокуса в HUD — 75 % длины.
- VII: ходьба всех видов, включая боссов и псов. Не входят: рывок кабана, прыжок рыси, снаряды, замахи и перезарядки приёмов, Жнец (тот же охват, что у множителя ходьбы сборки).
- VI–VIII действуют во всех боях похода, включая гарнизон, бои с боссом и события.

## 3. Границы (раздел «Границы требований» AGENTS.md)

- Поход играет 4 цвета на всех рядах (палитра ряда `rtColorsByRow` — только тумблер панели `colorsByRow`, выключен; гарнизон тоже 4). Первая версия спеки ошибочно считала, что поход играет палитру ряда; исправлено по находке core 16.10.2026.
- Пятый цвет — новый цвет цепи в симуляции (палитра до 5, `kit.colors` 5; `rollColor` тянет один бросок при любом размере — потоки не сдвигаются) и в виде (тело, кристалл на 5 частей, подсветка, колесо цвета песочницы). След на карте леса — палитра слоя леса, не меняется.
- Генерация: стартовые враги, расставленные вручную, держат цвета 0–3; цвет 4 приходит с выпавшим стартом, пополнением и волнами. Проверять отдельно выпавший старт, пополнение и цветовые механики (хамелеон, псы, «Близнецы», Тюремщик, Кастелян, «Смена цвета», «Призма», «Чужак», кристаллы).
- «Близнецы»: пары 0–2 и 1–3, у цвета 4 пары нет — так и оставить (на VIII «Близнецы» чуть слабее).
- Пролог, песочница (`colorCount` по умолчанию 4, максимум 5 — для снимков) и ступени 0–V не меняются.
- Цвета, которые несут смысл (радужное кольцо, огненный край, пунктир «Развилки»), пятым цветом не занимать.

## 4. Детерминизм и выпуск

- Ступень — поле похода `ash` (расширить `RtAshLevel` до 8); поход без поля или с 0–5 — прежний, байт в байт.
- Каждое правило — через ключи `Params` или поле кита (по образцу `floorScale`/`phaseScale` задачи 18): `focusMax` ×0,75, ходьба ×1,1, палитра 5; журналы старых походов не меняются.
- Выпуск в два шага. Шаг 1 — core: симуляция VI–VIII (вместе с пятым цветом), опыт, телеметрия; выбор показывает максимум VII, пока нет вида пятого цвета. Шаг 2 — ui: вид пятого цвета, затем открывается VIII.
- Бот: замер VI–VIII на 300 seed после шага 1 (эвристика, с датой). Скрипта «бот с прицелом в ядро» для похода нет — core берёт `scripts/realtime-economy.ts` или `scripts/garrisonBot.ts`.

## 5. Вид (ui)

- Выбор «Испытание: 0 · I · … · VIII» на «Новом походе», строка ступени, шапка карты — как сейчас.
- Пятый цвет (шаг 2): проверка различимости на снимке 1280×720 (врагов, кристаллов, подсветки цепи), отдельно против синего `0x79b0c4` при дейтеранопии.

## 6. Телеметрия

- `RunRecord.ash` 6–8; отчёт «Испытание» — по ступеням, длина цепи (медиана) по ступеням: ожидаем, что VIII снижает длину естественных цепей.

## 7. Приёмка

- Node: поход с VI — фокус ×0,75; VII — ходьба ×1,1; VIII — 5 цветов (выпавший старт и пополнение, ряды 1, 3, 5, несколько seed); ступени накопительны; 0–V и поход без поля — прежние хэши.
- Playwright один раз: выбор VI–VIII (после шага 1 — до VII), строка ступени.
- Снимки 1280×720: выбор ступени; арена с пятым цветом.
- Доки: `docs/realtime-slice.md` («Испытание»), `docs/realtime-telemetry.md`, README.
- Плейтест: «Пришлось ли лучше рисовать цепь?» — на ступенях VI–VIII.

## 8. Не входит

Скорость «Быстро» (Н2 отчёта) — пока нет (решение дизайна 16.10.2026: потолок — через навык цепи). Ступени по героям — когда появятся герои.

## 9. Решения дизайна

- **Пятый цвет цепи — mauve `0xa86a9a` (16.10.2026).** Предложение ui с макетом на 1280×720 (песочница, арена 1, цепь из четырёх врагов пятого цвета, толпа, элита пятого цвета, кристалл «Призма» с пятью гранями). Замер ui (CIEDE2000, в обычном зрении и при протанопии, дейтеранопии и тританопии по Machado 2009): худшее расстояние до четырёх цветов цепи — 21,1 / 17,9 / 11,8 / 10,0. У нынешней худшей пары из четырёх цветов — 24,2 / 12,5 / 8,6 / 7,2. До цветов со смыслом (проклятие, магия, подписи, огонь, цель, золото, лёд, лечение) — не меньше 16,5. Тело пятого цвета несёт свой знак (ромб). Plum `0xa0607e` отклонён: на снимке толпы он ближе к красному. Прежний запасной лавандовый `0xb69ad2` (`CHAIN_COLORS[4]`) убрать: при дейтеранопии он сливается с синим.
- «Призма» на пятицветной арене — пять граней. Вид — шаг 2 (после симуляции core).
- Проверка дальтонизма (ui, 16.10.2026; снимок толпы 2×2: обычное зрение, протанопия, дейтеранопия, тританопия; Machado 2009): mauve против синего `0x79b0c4` — 36,3 / 17,9 / 11,8 / 51,9; у нынешней худшей пары из четырёх цветов — 24,2 / 12,5 / 8,6 / 7,2. При протанопии и дейтеранопии ромбы mauve заметно темнее квадратов синего; самое слабое место — mauve против красного при тританопии (10,0), их различают яркость и знак. Принято, без изменений.
- **Шаг 1 core (ветка core/task45, de16873; в main — после выпуска задачи 43; 16.10.2026).** Правила — поля снаряжения `focusScale`, `walkScale`, `colors` 5 (журнал их несёт, хэш мира их включает), новых ключей `Params` нет. Ступени действуют во всех боях похода. Выбор 0…VII; VIII откроется после вида ui. Дефект вида: на экране конца похода кнопки ступеней не помещаются (передан ui).
- Замер бота core (финал, 300 seed, эвристика, 16.10.2026): V, VI, VII — 1/300 побед, медиана урона 44, медиана длины цепи 2,6; VIII — 2/300, урон 47, цепь 2,3. Бот рисует цепь за один такт, поэтому фокус ему не важен: VI и VII бот не измеряет. Пятый цвет укорачивает цепь бота (2,6 → 2,3), как и ожидалось. Мера ступеней — плейтест и телеметрия (медиана длины цепи по ступеням в отчёте).
- **Приёмка вида (16.10.2026).** По снимкам ui 1280×720 (ветка ui/task-45, 5dba09d на de16873 core; в main — после выпуска задачи 43): песочница с пятью цветами — тела mauve со знаком ромба, кристалл на 5 граней, цепь настоящей мышью по четырём телам пятого цвета; экран конца похода — «Испытание:» отдельной строкой, кнопки 0…VIII помещаются в колонку (дефект шага 1 исправлен), строка «+ пятый цвет на аренах»; экран «Поход» — 0…VIII. Лавандовый `b69ad2` убран. Принято. Текст выбранной кнопки ступени был бледным (золото на тёмном золоте) — ui сделал его светлым `#fff2c4` и жирным, рамка золотая (7accad2, realtime-ash 3/3); принято по снимку.
