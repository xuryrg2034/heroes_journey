# Задача 41. Узник на воле и три зелья

**Статус: спека дизайна, 16.10.2026. Не реализовано.** Источник — плейтест v68 (один тестер, 16.10.2026, 3 похода, победа над Кастеляном) и ответы пользователя. Все числа — гипотезы для плейтеста.

## 1. Что сказал пользователь

- Псы: «собаки понравились и у Кастеляна и просто псари. Есть удовольствие в том, чтобы спустить их на врагов». Убийств яростью пса за гарнизон — 29.
- Зелья: «у меня их просто очень много, я пью абсолютно не думая… Может стоит добавить ограничение на кол-во зелий». Победный поход: зелий получено 13, выпито 8, осталось 6 (около 72 HP лечения).
- Кастелян: «легко, простой босс… подошёл и закликал». Решение пользователя (вопрос с вариантами, 16.10.2026): **ждать шага 2** (решётка, рычаги, арбалет) — числа Кастеляна сейчас не меняем.
- Решения пользователя (вопрос с вариантами, 16.10.2026): кандалы — «Узник спускается»; зелья — «3 зелья».

## 2. А. Узник на воле (core — sim; ui — вид)

Правило: кандалы разрублены (проход рвёт их, как сейчас) — узник **срывается**: тот же закон, что сорвавшийся пёс (`houndFrenzy`, `vars.fz`). `houndFrenzy` с он бежит к ближайшему телу и кусает врагов, которых касается (`houndFrenzyDamage`; элита теряет пластину). Потом — обычный враг, его можно взять цепью; Ключник может снова надеть кандалы через `shacklePeriod`.
- Смерть Ключника снимает кандалы без срыва: узник просто свободен (иначе убийство Ключника стало бы тем же, что рубка, и порядок «сначала разруби» пропал бы).
- Убийства узником игроку не засчитываются (как ярость пса), в сводку — `chain.frenzyKills` (тот же счёт) и отдельно `garrison.riotKills`.
- Узник в срыве не берётся Ключником в кандалы.
- Подсказка у места: прежняя подпись «В кандалах — сначала разруби» остаётся; после первой рубки за поход — короткая вспышка «На волю!» над узником (подпись у места, без таблички, один раз за поход).

Почему: рубка должна давать то, что игроку уже нравится, — спустить кого-то на врагов. Закон срыва пса известен, новых знаков почти нет; решение игрока видно заранее: рубить кандалы и получить союзника на 6 с или бить узника позже.

Детерминизм: ключ `Params.prisonerRiot` (bool, хэшируется, по умолчанию false — прежнее поведение; журнал без ключа — прежний путь). Поход ставит true в `RT_RUN_FORCED`; песочница — true, панель «Гарнизон», «Узник срывается после рубки». Новых полей мира нет, пока ключ выключен. Подсветка = исполнение: подсветка не меняется (`cuts` уже показывает разрез).

Вид (ui): узник в срыве — тот же знак, что пёс в ярости (цвет, след), чтобы закон читался одинаково; сломанные кандалы падают с узника.

## 3. Б. Три зелья (core — поход; ui — вид)

Правило: в руке не больше **3 зелий лечения** (`healing`). Остальные расходники (холод, бомба, огонь) — без изменений.
- Находка, торговец, дар, ремесло на привале: при 3 зельях в руке выбор «лечение» **виден, но недоступен** с подписью у места «Рука полна». Сами предложения не меняются (выводы `forest/` для seed заморожены).
- Зелье, подобранное в бою (добыча), при полной руке не подбирается — лежит до конца боя.
- Стартовое зелье и награды входят в тот же счёт.
- Если в руке уже больше 3 (старый поход) — ничего не отнимаем; новые не приходят, пока не станет меньше 3.

Детерминизм: флаг похода `potionCap` (число, 3) пишется при создании нового похода; поход без флага (сохранения до задачи 41) — без предела, байт в байт прежний. Если добыча в бою — правило симуляции, нужен и ключ `Params` (`potionCap`, по умолчанию 0 = без предела); решает core.

Вид (ui): число зелий на кнопке предмета уже есть; при пределе — рамка кнопки «полна». Нового элемента HUD нет.

Почему: лечение зельями — главный источник HP у человека (72 HP за победный поход против 0 покупок лечения на карте). Предел возвращает решение «пить сейчас или беречь» и делает ценным лечение на карте и у торговца. Образцы: фляга Dead Cells (несколько зарядов), ограниченные заряды лечения в Hades и Slay the Spire (слоты зелий).

- Отчёт: раздел «Гарнизон» — срывы и убийства узниками; раздел «Предметы» — отказы «Рука полна».

## 5. Приёмка

- Node, настоящие команды: рубка кандалов → узник в срыве кусает врага, убийство не в зачёт игроку; смерть Ключника → узник свободен без срыва; `prisonerRiot: false` и журнал без ключа — прежний хэш. Поход: при 3 зельях выбор лечения в находке отклоняется; поход без флага — без предела.
- Playwright один раз, настоящая мышь: «Ров» в песочнице — цепь поперёк кандалов, после прохода узник бежит к врагу; поход с 3 зельями — находка показывает «Рука полна», лечение не берётся.
- Снимки 1280×720: узник в срыве; находка с «Рука полна»; кнопка предмета при пределе.
