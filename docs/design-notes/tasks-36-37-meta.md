=== ЗАДАЧА 36 «Опыт героя, открытия, рекорд глубины» (core — run и профиль; ui — экраны). После задачи 30. ===
Герой и профиль
- Id героя `cat` (кот-варвар). Профиль получает поле `meta` (новое; профиль без поля — мета с нуля, старые поля не трогать): `meta.heroes[heroId] = { xp, packs, record }`. Поход получает `heroId` при создании (без поля — `cat`).
- Мета считается только в походе без `?seed=` (как `RtProfile.won`); песочница и пролог её не трогают.
Опыт за поход (как счёт StS: глубина и трудность, а не убийства)
- Обычный бой выигран — 5; «Застава», элитный и прорыв — 10; Тюремщик — 30; финал леса — 50; подвиг — +5; победа похода — +25.
- Множитель «Испытания»: ×(1 + 0,1 × ступень), округление вниз.
- Ориентиры: смерть у Тюремщика ≈ 30; смерть на ряду 8 ≈ 70; победа леса ≈ 150–180.
Пороги и наборы (правило StS `UnlockTracker`)
- Шаги порогов: 60, 120, 180, 240, 300 (сумма 60, 180, 360, 600, 900). Дальше — новые наборы по мере нового контента, шаг 300.
- За поход открывается не больше одного набора. Остаток опыта переносится, но обрезается до «следующий порог − 1».
- Наборы по 3 предмета. В начале меты эти 15 предметов заперты (не выпадают ни в одном пуле похода):
  1. «Охотник» (60): `elite-hunter`, `finishing-blow`, событие `bone-wheel`.
  2. «Возврат» (180): молот `return-pass`, реликвия `relic-swift-feet`, событие `porcupine-nest`.
  3. «Близнецы» (360): форма `form-twins` (если задача 30 ещё не в походе — вместо неё `shockwave`), `prism`, событие `old-trap`.
  4. «Длинные цепи» (600): `long-arm`, `third-chain`, реликвия `relic-wide-circle`.
  5. «Иней» (900): `frost-edge`, реликвия `relic-blood-oath` и первая новая форма после задачи 30; пока её нет — набор из 2.
- Минимумы пулов при запертом: common ≥ 3 (whetstone, dew-flask, fifth-link), rare ≥ 3 (слот 0 «Заставы»), молотов 3 (Тюремщик — 3 из 3). Экран Тюремщика «oath + реликвии»: в начале 3 кандидата (`oath-hunger`, 2 реликвии); с гирей «1 из 4» показывает сколько есть (3). Если пул меньше нужного — показать меньше, не падать.
- События: заперты 3 из 14 (`bone-wheel`, `porcupine-nest`, `old-trap`); «Раненый волчонок» и «Бродячий точильщик» не запирать (через них приходят NPC задачи 37).
Детерминизм
- Поход получает при создании флаг `locked: string[]` — снимок запертого (как `schedule.seen`). Пулы фильтруют по нему. Без флага — прежние пулы, сохранение байт в байт. Решение дизайна (одобрено заранее): с флагом ассортимент того же seed отличается — это новые походы, выводы `forest/` для походов без флага те же.
- Опыт, наборы и рекорд считаются после похода из `RtRunState` (бои, подвиги, результат, ступень) — случайности нет.
Рекорд глубины
- `record = { row, won, xp }` на героя: самый дальний ряд (`rtReachedRow`, в run-рядах), была ли победа, лучший опыт за поход. С гарнизоном добавится уровень.
Экран конца похода (ui)
- Блок «Опыт»: «+N опыта» с разбивкой по строкам (бои, Тюремщик, подвиги, победа, «Испытание»), полоса героя заполняется с count-up (С3), отметка следующего порога.
- Набор открыт: три карточки переворачиваются (силуэт → предмет) со звуком награды. Это главный момент дофамина меты — без текста-таблички, имена на карточках.
- Рекорд: «Ряд 8 — новый рекорд» (только когда побит), прежний рекорд мелко.
- Новые предметы при первом появлении в предложении — знак «✦ новое» (как на карте).
Телеметрия: в записи похода — `xp`, разбивка, `pack` (открытый набор), `record` (побит или нет), снимок `locked` (число).
Приёмка
- Node: опыт на настоящих походах API (победа, смерть у Тюремщика, смерть на ряду 8, «Испытание» II); ≤ 1 набор за поход и обрезка остатка; запертое не выпадает ни в одном пуле (12+ seed, все источники: «Застава», брод, сундук, подвиг, дар, торговец, Тюремщик, события); минимумы пулов; поход без флага — байт в байт; `?seed=`, песочница, пролог — мета не меняется.
- Playwright один раз: поход до смерти — экран конца показывает опыт, полосу; второй поход после порога — карточки набора; рекорд.
- Снимки 1280×720 мне: экран конца с опытом, открытие набора, рекорд.
- Доки: `docs/realtime-slice.md` (мета), README, `docs/realtime-telemetry.md`.

=== ЗАДАЧА 37 «Лагерь „Очаг“ v1» (core — профиль, вынос, флаги похода; ui — экран лагеря, арт-заглушки). После 36 (общий профиль); экран ui можно начинать сразу по контракту ниже. ===
Поток
- Конец похода → кнопка «В лагерь» → экран «Очаг» → «В поход» (новый поход). Первый поход начинается как сейчас (пролог/карта); лагерь появляется после первого конца похода. «Новый поход» на карте — как раньше (без лагеря), чтобы не ломать привычку; кнопка «Лагерь» рядом.
- id в коде — `hearth` (`camp` занят веткой гоблинов в `mapGenerator.ts`).
Вынос ресурсов (валюта лагеря — «запас»)
- Победа — 100 % ресурсов похода. Смерть или брошенный поход («Новый поход» поверх начатого) — 50 % с округлением вниз, но не меньше min(ресурсы, 6). Потолок — 20 за достигнутый уровень (сейчас только лес: 20).
- Считается после похода по итоговым ресурсам. Запас — в профиле (`meta.hearth.stock`). Экран конца: строка «В лагерь: +N» и полёт значков (С3). Начало похода ресурсов из запаса не получает.
Экран «Очаг» (один экран 1280×720, ui)
- В центре — костёр (Очаг): полоса опыта героя, следующий набор (силуэты трёх карт и порог), рекорд глубины, кнопка «В поход». Сверху — запас со значком.
- Вокруг — 6 мест. v1: три NPC; три места — тёмные пустые (ничего не обещают текстом).
- Клик по NPC — облачко с репликой (по поводу, ниже) и улучшения NPC с ценой; купленное отмечено; нехватка — кнопка выключена с числом («нужно 8, есть 5»).
NPC v1 (имена проверены grep отчётом NPC; характер — `reports/Лагерь — NPC-личности.md`)
- Неясыть, сова-летописица. В лагере с первого раза. Улучшения: ур. 1 (4) «Два пути» — в начале похода выбор из 2 карт леса; ур. 2 (8) «Три пути» — из 3. Бесплатно: бестиарий (враги, которых герой встречал — данные `newSeen`/`seen`; вид, имя, одна строка) — мини-петля М1.
- Марфа, травница. Приходит, когда игрок в любом походе выбрал «Перевязать» у «Раненого волчонка» (`wounded-cub`, выбор `bandage`). Ур. 1 (4) «Склянка в дорогу» — +1 стартовый расходник (вид по потоку `hearth-herb` из открытых расходников); ур. 2 (8) «Выбор травницы» — вид из 2 на выбор.
- Ерофей, точильщик. Приходит, когда игрок купил заточку у «Бродячего точильщика» (`wandering-grinder`, выбор `grind`). Ур. 1 (4) «Правка» — +1 бесплатный переброс на экранах Тюремщика (молот и реликвия); ур. 2 (8) «Полный верстак» — экран молота Тюремщика показывает все открытые молоты (4 вместо 3).
- Запасной путь (события редки — ряды 6–8, одно из 11): NPC, не встреченный за 3 законченных похода после первого лагеря, приходит сам (реплика «Слыхала про тебя…»). Сначала Марфа, потом Ерофей.
- Ур. 3 (16) у всех — «после гарнизона»: в v1 показан замком, не покупается.
Задание NPC на поход (мини-петля М3, v1 — простое)
- Перед походом один NPC из пришедших (по seed похода, поток `hearth-quest`) даёт задание. Проверка — после похода по `RtRunState`, сим не трогает. Награда: +10 опыта и +3 к запасу (вне потолка выноса).
- Неясыть: «Дойди дальше прежнего» (ряд > рекорд, при рекорде 10 — «Пройди лес»). Марфа: «Вернись с 2 склянками» (≥ 2 расходника в конце, при победе или смерти). Ерофей: «Отруби гирю Тюремщику» (`severed`).
- Задание видно в облачке NPC и на экране конца («Задание Марфы: выполнено +10 опыта, +3 запаса»). Знака в бою нет.
Реплики (личность — по поводу, образец Inscryption: «первый раз + 2–4 повтора», причина прошлой смерти)
- На NPC около 30–40 строк: знакомство (ссылка на событие, где встретились), после победы, после смерти по причине (толпа, стрелок, сапёр, Тюремщик, финал, огонь), новый рекорд, покупка, выполненное и проваленное задание, 3–4 повтора без повода, 1–2 о другом NPC. Тексты — `docs/design-notes/npc-lines-v1.md` (пишет дизайн), данные — файл вида.
- Выбор реплики: самый конкретный повод из прошлого похода, иначе повтор по кругу; «первый раз» — один раз за профиль.
Детерминизм
- Поход при создании получает `hearth` (новое поле; без него — прежний поход байт в байт): `{ maps?: 2|3, startItems?: ItemKind[], jailerRerolls?: number, hammerAll?: true, quest?: {npc, id} }`. Потоки по имени: `hearth-herb`, `hearth-quest`, `hearth-maps`. Карты на выбор — seed-кандидаты из основного seed по соли `hearth-maps`; выбранный становится seed похода; выводы `forest/` для этого seed те же.
- Профиль: `meta.hearth = { stock, levels: {owl, herb, smith}, met: {herb?, smith?}, lines: {...seen} }`. Встреча NPC — флаг профиля при исходе события; исход события и поток события не меняются.
Арт
- Три портрета NPC и фон лагеря — по `docs/character-art-style.md` (дизайн делает через Codex, скилл `character-art`). До арта — заглушки силуэтами (ui).
Телеметрия: вынос (`carry`: ресурсы, доля, потолок), запас до и после, покупки, выбранная карта, задание и итог, клики по NPC.
Приёмка
- Node: вынос — победа 100 %, смерть 50 % и пол 6, брошенный поход, потолок 20; покупки и нехватка; флаги `hearth` у похода (стартовый расходник, переброс у Тюремщика, все молоты, 2/3 карты) — на настоящих походах API; задание засчитывается по настоящему походу и не засчитывается без условия; встреча Марфы и Ерофея — по настоящему исходу события; поход без `hearth` — байт в байт.
- Playwright один раз: конец похода → лагерь → покупка «Два пути» → «В поход» → выбор из 2 карт; клик по NPC — реплика.
- Снимки 1280×720 мне: лагерь пустой (после первого похода), лагерь с тремя NPC, облачко с улучшениями, выбор карты.
- Доки: `docs/realtime-slice.md`, README, `docs/realtime-telemetry.md`.
