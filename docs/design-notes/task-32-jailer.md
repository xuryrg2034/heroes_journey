=== ЗАДАЧА 32 «Бесцветный Тюремщик, больше HP» (core — sim; ui — вид). Можно параллельно с правкой форм. ===
Правило:
- Ядро Тюремщика (`jailer`) бесцветное. Его берёт цепь любого цвета, звеном в любом месте цепи, в том числе первым.
- Бесцветное ядро не задаёт и не меняет цвет цепи. Цвет цепи задаёт её первый цветной враг. В счёт «Смены цвета» ядро не входит. Для «Чужака» оно не чужое, для «Близнецов» — не цвет пары.
- Отказы прежние: щит спереди, «уже в цепи», расстояние, видимость.
- Гиря (`jailer-weight`) сохраняет свой цвет: урок «часть» — отрубить гирю цепью её цвета. «Свисток» зовёт врагов цвета гири, как сейчас (`vars.wc`).
- HP ядра: 2 → 5. Пластины (3), HP гири (3) и приёмы не трогаем. Число — гипотеза, проверит плейтест.
Детерминизм:
- Ключи `Params.jailerColorless` (bool) и `Params.jailerHp` (число), хэшируются. По умолчанию — прежнее: цвет есть, HP 2. Журнал без ключей — прежний путь.
- Арена «Тюремщик» песочницы и бой Тюремщика в походе включают ключи для себя, как `bossClears`: `jailerColorless` true, `jailerHp` 5. Панель: группа босса, «Тюремщик: бесцветный», «Тюремщик: HP ядра» 2–10.
- Подсветка = исполнение: `planChain`, отказы и П1 читают одно правило цвета (бесцветное звено — через ту же функцию цвета, что `colorJoin`/`colorSegments`).
Ui:
- Ядро рисуется без цвета команды: нейтральная (серая) обводка и кольцо HP вместо цветного. Подсветка кандидата у ядра — при цепи любого цвета.
- Полоса босса показывает новый запас HP. Значение не подписывать текстом.
Приёмка:
- Node: журнал без ключей — прежний хэш (бой f03 похода `rmv9oikad-e56769f5` из лога 15.10.2026 и фикстуры задачи 28). С ключами: цепь красного цвета берёт ядро и идёт дальше по красным; цепь, начатая с ядра, берёт цвет следующего врага; ядро не сдвигает счёт смены цвета; подсветка = исполнение на настоящих командах.
- Playwright один раз, настоящий ввод: бой Тюремщика, цепь одного цвета через ядро.
- `docs/realtime-elite-behaviors.md` (Тюремщик), README при необходимости.
- Снимки 1280×720: ядро без цвета; подсветка цепи двух разных цветов к ядру.
- Плейтест (эвристика): время боя и доля отрубленной гири; ориентир — убит с первой попытки 50–70 %.

Приёмка вида (15.10.2026, ui/task-32 0049443, снимки 1280×720): ядро серое, плашка на поясе пустая — знак «любой цвет» не нужен (четырёхцветный знак уже значит кристалл; бесцветность учит кольцо кандидата при любой цепи). Кольцо кандидата при красной и синей цепи, гиря чужого цвета затемнена, полоса 5 HP + 3 пластины — принято.
