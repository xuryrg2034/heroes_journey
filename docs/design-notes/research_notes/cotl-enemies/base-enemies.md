# Cult of the Lamb: рядовые враги четырёх биомов

Дата проверки: **18.10.2026**. Источник: локальная декомпиляция сборки пользователя, извлечённая **15.10.2026**; точная версия игры не установлена. Это исследование чужой реализации, не спецификация Ashen Oath и не отчёт о плейтесте.

## Как читать доказательства

Корень источников — `D:/ashen_research/games/cult_of_the_lamb/`. Ссылка вида `EnemyHopper.cs:259` означает `decomp/EnemyHopper.cs`, строку 259. Каталог — `copy/data/catalog.json:1`, массив `m_InternalIds`; JSON однострочный, поэтому для него дополнительно указан точный путь/имя ресурса. Английские строки — `extracted/loc_en.json`. В репозиторий помещены только выводы, файлы игры не копировались.

**Три разных уровня:** запись `Enemy` — идентификатор; имя `.prefab` — существующий адрес ресурса; класс — реализация поведения. Без содержимого prefab нельзя доказать ни соединение всех трёх, ни включённые флаги, ни появление врага в конкретной комнате. В таблицах класс возле похожего имени — **кандидат на соответствие**, если явно не указана прямая связь в коде. Само описанное поведение класса проверено. Имена на русском описательные, не заявлены как официальная локализация.

**Все ответы игрока — аналитический вывод из поведения**, не проверка оптимальной тактики. Числа из инициализаторов не считаются текущим балансом. Даже константа времени корутины может зависеть от масштаба времени анимации. Боссы, минибоссы, Свидетели и Winter/Rot исключены из основного ростера.

Участие призванного в множителе относится к руно игрока: `Health.cs:2161` вызывает `PlayerFleeceManager.IncrementDamageModifier`, а тот проверяет `PlayerFleece == 1` (`PlayerFleeceManager.cs:217`). Это не усиление атаки паука.

`Enemy Spider Monster` исключён: в его смерти прямо создаётся последователь с именем лидера Dungeon4 (`EnemySpiderMonster.cs:975`). Это код босса Shamura, несмотря на отсутствие слова Boss в адресе.

## Поправки к прежнему разделу F

1. **Лассо громилы:** `LassoPlayer` и `ThrowRock` объявлены (`EnemyBrute.cs:178`, `:246`), но поиск по классу не обнаружил вызовов. Реальный видимый путь `ChasePlayer` использует отмеченный удар по площади. Нельзя подавать лассо как установленную атаку текущего обычного громилы.
2. **Дозорный:** появление группы стоит после `WaitForSeconds(5/6)`, а `1.2666667` — ожидание после появления (`EnemyScout.cs:100`, `:106`); прежний текст смешивал их и приписывал интервал между бойцами.
3. **Ядовитый прыгун:** замена выстрела на `PoisonBomb`, а не ядовитое кольцо (`EnemyHopperBurpPoison.cs:12`).
4. **Кулдаун Burp:** `lastBurpedFliesTimestamp` — поле экземпляра, не `static` (`EnemyHopperBurp.cs:18`). Это не общий лимит всех плюющихся врагов комнаты. Статический `LastArcherShot` у лучника — другой случай (`EnemyArcher.cs:20`).
5. **Шипастая медуза:** `EnemyJellyFish.AttackRoutine` создаёт взрыв; регулярная атака «иглами с двух единиц» в прочитанном классе не установлена.
6. **Гнездо:** наследование `EnemySpiderSpawner` от паука не доказывает связь с `Spider Nest`; `CanIncreaseDamageMultiplier` нельзя переводить как увеличение боевого урона призванного врага.
7. **Многоножка:** урон через тело передаётся основному здоровью. Совет бить исключительно голову не вытекает из этой реализации.
