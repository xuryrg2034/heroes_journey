## Как читать схемы

Синий «Я» — старт героя. Охристые точки — обычные враги, красные буквы — особые виды, фиолетовые — босс и его части. Золотое кольцо отмечает цель/элиту. Цвета значков обозначают роли, **не цвета цепей**. Зелёная стрелка — выход, фиолетовые квадраты — кнопки, огонь — жаровни. Серо-зелёные прямоугольники — стены, зелёные круги — деревья, голубое — вода, тёмное — обрыв, лиловое — тёрн.

В составах: `A` — авторская первая группа, `B` — обычный враг, `W` — волк; `F`/`floor` — целевое общее наполнение с учётом особых врагов. Это не число дополнительных врагов поверх нарисованных. Для тролля отдельно учитываются части босса и его периодические группы.

Сплошные линии — предполагаемые пешие подходы; пунктир — маршруты с возможным проходом цепью/прыжком. Это намерения игрока, а не вычисленный прогноз цепи. Зелёные пунктирные круги — области для проектирования пополнения; не гарантированные точки появления и не радиусы персонажей.

Геометрия и размеры следуют [карточкам арен](../arena-cards.md), составы — [рецептам](../encounter-recipes.md). Точные координаты конкретизированы для изображения. Их ещё нужно проверить в движении, с реальными радиусами тел, цветами, дальностью цепи, видимостью и правилами пополнения. Схемы не показывают финальный арт или работу камеры. Разные размеры поля вписываются в область просмотра: сравнивать масштаб следует по сетке и подписям единиц.

«Сейчас» — снимок авторских шаблонов кода от 18.10.2026 с `markedGoals=true`, **без** ростера, набора похода и динамического пополнения. Пустота в таком шаблоне не означает пустой бой в игре. «Предложение» показывает возможную первую группу; остальной поток не изображён.

## Воспроизведение

Из корня проекта:

```powershell
# Необязательно: обновить снимок текущих шаблонов из кода.
npx tsx docs/design-notes/research_notes/act1-redesign/atlas/export-current.mts
# Собрать автономный HTML, JSON и SVG.
node docs/design-notes/research_notes/act1-redesign/atlas/build-atlas.mjs
# Проверить интерфейс и экспортировать PNG через установленный Playwright/Chromium.
node docs/design-notes/research_notes/act1-redesign/atlas/render-exports.mjs
```

Исходники предложений — `proposals-a.mjs` и `proposals-b.mjs`. Сборка пишет только артефакты в эту папку; игру не запускает и её правила не меняет.

Проверка 18.10.2026: Chromium открыл автономный файл, переключил все 26 вариантов, слои, сравнение, увеличение, поиск и восстановление варианта из URL; ошибок JavaScript нет. PNG просмотрены визуально. Это проверка документа и его интерфейса, не плейтест уровней.
