# Задача 44. Сплавы: две части — новое правило цепи

**Статус: спека дизайна, 16.10.2026. Не реализовано.** Основа — отчёт [«Сборки — разнообразие и BALL x PIT»](<reports/Сборки — разнообразие и BALL x PIT.md>) (предложение П1). Все числа — гипотезы для плейтеста.

## 1. Зачем

Пользователь (16.10.2026): «потолок скилла довольно низок… смысл игр, на которые мы пытаемся опираться, не столько в сложности, сколько в разнообразии сборок. Тот же самый BALL x PIT — прям чувствую будущий хит».

Разрыв (отчёт, раздел 3): в походе 4–6 выборов сборки, ни один предмет не превращается в другой, на карточках нет связей — у похода нет цели сборки, походы похожи. В BALL x PIT цель забега — «соберу эволюцию»: рецепт виден, к нему стремятся.

Решения пользователя (вопрос с вариантами, 16.10.2026): первый шаг — **сплавы**; сплав происходит **на привале**; ступени «Испытания» на навык — **параллельно** ([задача 45](task-45-trial-skill.md)).

## 2. Правило

- **Рецепт** — форма (или молот) + талисман-счётчик → сплав: один предмет с новым правилом цепи вместо двух.
- **Карточка** половины рецепта показывает строку «Сплав: с „…“ → „…“» (на экране выбора и в сборке).
- **Гарантия пары.** Взял одну половину — на следующем экране талисманов (выбор талисмана, «Застава», подвиг с наградой-талисманом, торговец) одно место — её пара, если её ещё нет в ките. Свой бросок узла (соль), поток `talismans` не тратится.
- **Сплав на привале.** Обе части в ките — на привале появляется вариант «Сплав: „…“» рядом с «Лечением» и ремеслом. Выбор сплава занимает привал (лечения и ремесла на этом привале нет). Не выбрал — вариант остаётся на следующих привалах.
- Сплав **сильнее суммы частей** — это награда (решение дизайна; рост лёгкости компенсирует [задача 45](task-45-trial-skill.md)).
- Сплав занимает слот формы своей формы-части; счётчик-часть уходит из кита.

## 3. Три первых рецепта (только из предметов, что уже в пуле похода)

| Форма / молот | Талисман | Сплав | Новое правило |
| --- | --- | --- | --- |
| Печать | Иней на клинке | Ледяная печать | Выжившие внутри кольца замерзают, как от холода-расходника: 3 с, хрупкость ×2 (следующий удар цепи ×2); длительность — наибольшая из оков «Печати» и 3 с |
| Прямая | Длинная рука | Копьё | Пробой вдвое длиннее (3,75) и снимает с элиты 2 пластины вместо одной |
| Возврат | Добивание | Бумеранг | Второй проход «Возврата» идёт с полной силой (без деления на 2), если последнее вражеское звено погибло; цепь кончилась на выжившем — прежняя половина |

Подсветка (`planChain`) показывает правило сплава так же, как сделает проход: длину пробоя «Копья» и две пластины, заморозку «Ледяной печати» (знак инея на телах внутри кольца), силу второго прохода «Бумеранга».

Правила частей остаются у сплава: «Копьё» — пробой «Прямой» и окно R «Длинной руки» (R на длину пробоя не влияет); «Ледяная печать» — оковы «Печати» и мороз последнего выжившего от «Инея»; «Бумеранг» — щит ×2 от «Добивания». Холод «Ледяной печати» — на всех, кроме Жнеца (как весь холод), включая элит и ядро Тюремщика.

## 4. Вид (ui)

- Строка рецепта на карточке; когда пара собрана — мягкая отметка на обеих карточках в сборке («сплав на привале»).
- Привал: вариант «Сплав» с иконкой двух частей → итог.
- Момент сплава: короткая анимация слияния двух иконок в одну, звук (без длинной сцены).
- Подсказки — у места, без табличек.

## 5. Детерминизм

- Флаг похода `fusions` при создании; поход без флага — прежний, байт в байт. Гарантия пары и вариант привала — только с флагом (свои соли; выводы `forest/` для seed не меняются).
- Правила сплавов — модули `sim` (по образцу `frostPass.ts`, `pierce.ts`) по id сплава в ките; журнал без id сплава — прежний хэш.
- Песочница: три сплава в меню талисманов и группа панели «Сплавы».
- Подсветка = исполнение на нескольких seed.

## 6. Имена

Новые имена «Сплав», «Ледяная печать», «Копьё», «Бумеранг» — проверены по коду 16.10.2026: совпадений нет. Слово «сплав» в комментарии `frostPass.ts` и в отчёте значит «два молота на одном пути» — это внутренний термин, игроку не показывается; в документах после задачи 44 так не писать.

## 7. Телеметрия

- `RunRecord`: половины рецептов (ряд взятия), пара собрана (ряд), сплав выбран (ряд, узел) или отказ на привале.
- `FightSummary.build.fired`: срабатывания правил сплава.
- Отчёт: раздел «Сплавы» — доля походов с собранной парой, со сплавом, ряд сплава, победы со сплавом и без.

## 8. Приёмка

- Node, настоящие команды журнала: каждый сплав делает своё правило; подсветка = проход на нескольких seed; журнал без id — прежний хэш; поход без флага — прежний.
- Поход: взял половину — на следующем экране талисманов место пары (на нескольких seed); привал с обеими частями предлагает сплав; после выбора — один предмет вместо двух.
- Playwright один раз, настоящая мышь: песочница «Ледяная печать» — кольцо замораживает; поход — сплав на привале.
- Снимки 1280×720: карточка с рецептом, привал со сплавом, подсветка каждого сплава.
- Доки: `docs/realtime-prototype.md` (раздел форм и сплавов), `docs/realtime-slice.md` (привал), README.
- Плейтест: «Была ли у похода цель сборки?», «Отличался ли этот поход от прошлого?».

## 9. Не входит

Герои со своим законом (П2), уровни предметов (П3), архетип старта (П4) — после плейтеста сплавов. Больше трёх рецептов — после плейтеста (кандидаты из отчёта: «Радужный огонь», «Подрыв», «Ледяная волна»).

## 10. Ответы на вопросы core (16.10.2026)

Core нашёл в коде (план помощника, кода нет): «Печать» уже держит выживших холодом 1,5 с (от 8 звеньев 2 с) — «замерзают на 2 с» ничего бы не добавило; пробой «Прямой» уже бьёт сквозь щит — «сквозь щит» у «Копья» не ново; мета запирает части рецептов («Добивание» 60 опыта, «Возврат» 180, «Длинная рука» 600, «Иней на клинке» 900). Решения дизайна:

- «Ледяная печать»: холод расходника 3 с с хрупкостью ×2 (таблица раздела 3). «Копьё»: длина ×2 и 2 пластины; слова «сквозь щит» убраны.
- **Мета.** Гарантия пары и строка рецепта — только когда обе части доступны в этом походе. Рецепт запертую часть не открывает. Сплавы появляются по мере открытий меты: «Бумеранг» с 180 опыта, «Копьё» с 600, «Ледяная печать» с 900. Это разнообразие от меты, а не постоянная сила (план уровней, решение 08.10.2026). Первые походы новичка — без сплавов.
- Флаг `fusions` — только вместе с `forms`. «Возврат» — форма поля «Путь».
- Гарантия пары — следующий экран из: «Застава», награда события, сундук, подвиг, экран форм Тюремщика, торговец (по обычной цене талисмана). Экраны клятв и реликвий — нет. Гарантия выше редкости: редкая часть ставится и там, где только обычные. Место — последнее; редкое место «Заставы» и место формы другого поля не трогать; выпала сама — ничего не менять. Гарантия разовая: отказ — дальше обычные правила.
- Сплав занимает поле своей формы-части («Конец» или «Путь»). Позже взятая форма того же поля заменяет сплав (обе части пропадают; замена видна на карточке). Части после сплава уходят из пула навсегда.
- Числа — ключи `Params` при id сплава (`fusionSpearFactor` 2, `fusionSpearPlates` 2, `fusionIceTime` 3, `fusionIceBrittle` true), группа панели «Сплавы».
- Привал: сплав доступен при `restNoHeal` и «Клятве голода», выбор сплава снимает `restNoHeal`; привалы гарнизона — тоже.
- «Бумеранг» при «Быстрых ногах»: щит ×2 «Добивания» не работает (как сейчас); гарантия «Добивания» при «Быстрых ногах» не выдаётся.
- Песочница: меню выдаёт сплав с частями; «Длинная рука» внутри «Копья» работает по окну песочницы «каждая 4-я цепь».
- Форма-пара у торговца стоит как редкий талисман (8): у форм нет своей редкости (ответ core, 16.10.2026).
- Гарантия не предлагает форму, если её поле уже занято сплавом: иначе гарантия подталкивала бы разрушить сплав.
- Остаток, принят: если последнее звено «Бумеранга» погибло до прохода, бег идёт с полной силой при подсветке «половина». Это тот же класс, что принят для «Прямой»: мир изменился в пользу игрока.
