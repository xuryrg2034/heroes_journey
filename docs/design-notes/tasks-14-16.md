=== ЗАДАЧА 14 «Котомка у двери» (сим core + вид ui) ===
- Где: каждый бой похода, где дверь открывается по целям, кроме финального босса. Не в прологе.
- Когда: появляется у двери, когда цели выполнены.
- Счёт: убийства ПОСЛЕ целей (любым способом, как зачёт убийств игрока). Три ступени: 10, 20, 35 убийств → +1, +2, +3 ресурса (всего 6).
- Риск: любой урон по герою (касание, стрела, взрыв, перебор гоблина) сбрасывает прогресс ТЕКУЩЕЙ незаполненной ступени к её началу. Заполненные ступени не теряются.
- Выплата: при выходе в дверь — все заполненные ступени. Вид ресурса — из нового потока арены (напр. 'bag'). Смерть — поход окончен, как сейчас.
- Вид (ui): мешок у двери с тремя метками; число «12/20» над ним; заполненная ступень — вспышка и «+2»; удар — метка тускнеет, короткий «сброс». На экране итога боя — «Котомка: +3». Ничего в HUD сверху.
- Телеметрия: ступени, убийства после целей, сбросы, выплата.
- Приёмка: Node — 10/20/35 дают 1/3/6; удар сбрасывает только текущую ступень; выплата при выходе; повтор журнала — тот же хэш; старый журнал — без котомки. Playwright настоящим вводом — мешок появляется после целей, число растёт от цепи.

=== ЗАДАЧА 15 «Лечение на карте» (слой похода core + вид ui) ===
- Кнопка на карте похода (шапка, рядом с HP): «Лечение +2 HP — N ресурсов». Доступна между боями всегда.
- Цена: первая покупка 2 ресурса, каждая следующая в этом походе +1. Платёж — как у торговца (shopPayment, с самых многочисленных).
- Нельзя: при полном HP (кнопка выключена с причиной «HP полное»), без ресурсов («Нужно N, есть M»). Лечение не выше максимума.
- Торговец и привал — без изменений.
- Телеметрия похода: покупки лечения (ряд, цена, HP до/после).
- Приёмка: Node — цена 2, 3, 4…; полное HP — нельзя; сохранение/загрузка держат цену. Playwright — клик лечит и тратит ресурсы.

=== ЗАДАЧА 16 «Подвиги» (слой похода + сим core + вид ui) ===
- У каждого боевого узла похода (обычный бой, прорыв, бой события; не Тюремщик, не финал) — один необязательный подвиг. Бросок — новый поток похода (напр. 'feats') при генерации/открытии узла; seed узла даёт тот же подвиг.
- Виды (только очки и время, по слову пользователя):
  1. «Набери N очков» — очки этого боя ≥ N. N по ряду: ~1,5 × медианы очков ряда (замер ботом — эвристика с датой).
  2. «Продержись N с после целей» — N: ряды 1–3 → 20, 4–6 → 30, 7+ → 40. Выполнен в момент, когда прошло N с после целей и герой жив.
  3. «Продержись N с на арене» — время боя ≥ N: ряды 1–3 → 60, 4–6 → 80, 7+ → 100.
- Награда (видна заранее): ресурсы 3 (ряды 1–4) / 4 (5+) — 75 %; талисман на выбор из 2 — 25 % (бросок тем же потоком). Выдаётся при выходе в дверь. Провал — без потерь.
- Карточка узла: строка «Подвиг: продержись 30 с после целей → 3 ресурса».
- В бою: короткая строка у таймера в HUD: «Подвиг 12/30 с» или «Подвиг 240/400»; выполнен — «Подвиг ✓» + звук. (Новое в HUD — решение дизайна.)
- Экран итога боя: «Подвиг: +3 ресурса» / выбор талисмана.
- Телеметрия: подвиг предложен/выполнен, вид, N, время выполнения, награда.
- Приёмка: Node — подвиг по seed узла стабилен, разные seed дают разные виды; каждый вид выполняется настоящими командами журнала; награда только при выходе; старые сохранения — без подвигов. Playwright — строка на карточке и в HUD, «✓» при выполнении.

ПОРЯДОК: 14 и 15 первыми (котомка даёт ресурсы, лечение их тратит), 16 следом. Пуш одним пакетом или двумя — на усмотрение core. Снимки 1280×720: мешок у двери (пустой, на ступени, после сброса), кнопка лечения, карточка с подвигом, HUD с подвигом.
