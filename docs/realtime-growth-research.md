## 2. Главные выводы исследования

1. **Сборку создаёт условие + триггер + смена формы действия.** Плоская прибавка её не создаёт. Образцы: счётчики StS («каждая 10-я атака ×2»), молоты Hades (меняют форму оружия), джокеры Balatro (меняют правило счёта), рецепты VS (пара → эволюция).
2. **Разнообразие встреч — из сочетаний, а не из HP.** Роли врагов (Doom 2016: «боевые шахматы»), аффиксы элит с плюсом и минусом (Brogue, SPD, Diablo 3), модификаторы комнат (Пакт Hades).
3. **Второй биом меняет три вещи:** форму пространства, семейство врагов, 1–2 опасности. Системы остаются. Рост HP умеренный: Gungeon ×1,3 за этаж, RoR2 ×1,15 за этап.
4. **Лестница сложности — одно правило на шаг.** В StS из 20 шагов только 6 — «сильнее/толще». Награда — один раз, за первую победу на новом шаге (Hades).
5. **Квесты лучше всего учат приёму.** RoR2: «босс за 15 с» → предмет агрессии. Цели видны заранее, игрок сам выбирает.
6. **Мета вширь, не ввысь.** Постоянная сила делает ранние забеги пустыми и подменяет навык. Это совпадает с нашим принципом. HAYAI (ближайший аналог) держится вообще без меты: персонажи + таблица.
7. **Цвет у нас занят цепью.** Роль врага показываем силуэтом, размером, движением, значком и единым телеграфом.

Не рекомендую: постоянную силу (HP, урон цепи) за валюту. Противоречит принципу проекта и подменяет навык.

## 6. Замок — второй биом

**Основа — наш черновик** [castle-roster.md](biomes/castle-roster.md): шахматы, мебель, кухня, магия, колдун, 5 актов. Он уже отвечает выводу 3: своя геометрия угроз, свои опасности, своё семейство. Стиль — whimsical dark fantasy, живой замок, — подходит лучше, чем «обычный гарнизон» из исследования.

Перевод в реальное время:

| Черновик | В реальном времени | Связь с цепью |
| --- | --- | --- |
| Ладья, слон | Турели: объявленная линия / диагональ. **Удар получает первое тело на линии** (замковый закон; лесной лучник пробивает всех) | Тела — укрытие; порядок убийства открывает линии |
| Конь | Ныряльщик: прыжок «буквой Г» по телеграфу | Уйти с клетки приземления |
| Пешка | Строй, медленный шаг; на отмеченной линии превращается | Строй — готовая цепь |
| Королева | Мини-босс: чередует прямые и диагонали, режим виден заранее | — |
| Король | Цель арены (хранитель ключа), аура соседям | Сломать строй |
| Злой шкаф | Объявляет падение, давит, становится стеной навсегда | Поле меняется за бой |
| Живая дверь | Проём по ритму | Цепь проходит только в открытую |
| Котёл, рой приборов | Разлив на время, залп по объявленным зонам | Опасно и для врагов |
| Бочка | Устройство: звено цепи запускает её | Инструмент игрока |
| Колдун | Босс: оживляет мебель, меняет правила фигур | Экзамен биома |

Добавить из исследования: **рычаг как звено цепи** (проход дёргает рычаг), **цветные печати** на полу (+1 сила звену своего цвета), **шипы по такту**, **ров** (цепь — мост, как обрыв леса). Рост: HP врагов замка ×1,3 к лесу, у элит 1 аффикс с первого ряда; сила цепи не меняется.

Требует решения пользователя: исследование предлагает «звонаря» (колокол тревоги). Колокол удалён 30.09.2026 по решению пользователя — без нового решения не возвращаем.
