## 3. Что не переносим

- Прогноз хода и его совпадение с исполнением. Вместо прогноза — телеграфы врагов в реальном времени и подсветка допустимых звеньев.
- Пошаговые фазы, злость по очереди, пополнение клеток.
- Авторские расстановки по клеткам. Бой задаётся шаблоном арены: препятствия, цели, состав и таблица появления.
- Анализатор уровней по ходам. Вместо него — бот-симуляция арены с фиксированным шагом и seed (метрики: время до целей, урон, длина цепей).

Детерминизм остаётся: фиксированный шаг симуляции и seed. Это нужно для тестов и записи повторов, не для прогноза.

## 4. Разнообразие: враги и способности

### Враги первой волны (у каждого — одна механика, и каждый использует ходьбу героя)

| Враг | Механика в реальном времени | Решение игрока |
| --- | --- | --- |
| Кабан (есть) | Объявленный рывок по линии, расталкивает толпу | Уйти с линии или подставить толпу |
| Волк (есть) | Сильнее рядом с другими волками | Разбить стаю |
| Щитоносец | Щит спереди медленно поворачивается к герою. Звено со стороны щита не берётся | Обойти ходьбой и взять сзади |
| Лучник | Держит дистанцию. Объявляет линию (полоса 1 с), стрела бьёт всех на линии, и врагов тоже | Уйти с линии или поставить под неё толпу |
| Шаман | Держится за толпой. Раз в N с превращает соседнего слабого в крепкого (видно заранее) | Пробиться к нему раньше |
| Сапёр | При гибели взрыв по кругу: бьёт всех, героя тоже | Где кончить цепь; взрыв как инструмент |
| Дикобраз | Звено в цепи с дикобразом ранит героя | Цепь в обход дикобраза |
| Копейщик | Зона перед копьём: проход героя по цепи через зону ранит | Порядок звеньев в цепи |

Позже: медведь (ярость после ранения), паук (паутина замедляет и рвёт звено), Зверовод. Боссы: Тюремщик, Тролль, Главарь — каждый как арена с фазами.

### Способности героя

- **Энергия** копится за убийства (как прыжок сейчас). Клавиши: Пробел — прыжок, Q — круговой удар.
- **Расходники** — клавиши 1–4, прицел мышью: холод (зона замерзает, механики врагов выключены), бомба, лечение, огонь.
- **Талисманы цепи** — новые модификаторы. Примеры: «якорь у героя» (если не войдёт в базовые правила), «+0,25 радиуса», «кристалл за 5 убийств» (есть), «последний удар цепи — взрыв».

## 5. Этапы

| Этап | Содержание | Готово, когда |
| --- | --- | --- |
| 1. Ядро | Движок реального времени в основной ветке отдельным модулем: фиксированный шаг, seed, данные врагов и арен. Код прототипа — основа. Пошаговая игра пока работает рядом. | Арена прототипа запускается из нового модуля; тесты детерминизма зелёные. |
| 2. Вертикальный срез | Поход по карте с аренами вместо пошаговых боёв: 4 новых врага первой волны, 8–10 шаблонов арен, расходники и способности, элиты. | Пользователь проходит поход целиком; плейтест по протоколу. |
| 3. Лес целиком | Все враги первой волны, боссы, талисманы и события под реальное время, бот-симуляция арен. | Метрики арен по боту в документах с датой. |
| 4. Удаление пошагового режима | По решению пользователя: удалить пошаговый движок, анализатор, авторские поля; обновить документы. | Документы описывают только реальное время. |

## 6. Решения для пользователя

1. Утвердить переход: пошаговые бои заменяются аренами реального времени, карта и мета остаются.
2. Пошаговую игру удаляем после среза (этап 4) или раньше?
3. Якорь у героя — базовое правило или талисман? Решить на плейтесте этапа G.
4. Первые 4 новых врага среза. Предложение: щитоносец, лучник, сапёр, дикобраз.
5. Энергия за убийства для способностей или перезарядка по времени? Предложение: энергия, как сейчас.
