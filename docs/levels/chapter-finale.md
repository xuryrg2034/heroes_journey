# Финал первой главы и развилка

После первых тринадцати боёв идут Тюремщик (14) и выбор одного из двух самостоятельных боёв: «Через ворота» (15) или «Заставить колокол замолчать» (16). После любой ветки интерфейс предлагает лесное испытание. Все шестнадцать боёв доступны напрямую с начального экрана. Ограничения предметов и способностей предыдущих уроков сохраняются.

Данные находятся в `src/game/tutorialLevels.ts`. `nextLessonIndices` содержит индексы с нуля: у Тюремщика `[14, 15]`, у обеих веток `[]`. Отсутствующее поле сохраняет линейный переход; `nextTutorial()` не выбирает ветку автоматически. `startTutorialChoice(index)` проверяет победу и список доступных переходов.

## Общие условия

Все три новые карты имеют размер 7×6, пять обычных цветов, 5 HP, 0 начальной энергии и пустой инвентарь. Доступны ранее открытые прыжок и холодный настой; настой не выдаётся бесплатно. Рядовые враги слабые, с 0 HP, но остаются живыми до положительного попадания. Пополнение случайно выбирает цвета по весам палитры, в которой доступны все пять цветов. Отдельная волна не обязана содержать каждый цвет. Выжившие враги не перекрашиваются, и каждый бой можно повторить с той же начальной расстановкой и RNG.

Красные и синие группы сохраняют основные маршруты. На всех трёх картах зелёная пара занимает C6–D6, охристая — E6–F6; фиолетовая группа находится в E5–F5 у Тюремщика и в квадрате F4–G5 на обеих ветках. Эти соседние группы образуют дополнительный южный путь. Обозначения карт: `#` стена, `H` кот, `R/G/B/O/V` красный/зелёный/синий/охристый/фиолетовый, `X` цель, `L` рычаг, `F` жаровня; в ветке выхода G1 — дверь вместо врага.

Карты ниже показывают авторское начальное поле. Маршруты — примеры для текущего seed и указанной последовательности действий: одинаковый повтор воспроизводит случайное пополнение, но цвет не закреплён за координатой. Буквы обозначают столбцы, числа — строки с единицы. Каждый пункт маршрута — отдельный ход, если не указано иное.

## 14. Тюремщик

```text
##RRBBB
RRRRBBB
#RRRXBB
#RRRFBB
#RLRVVB
#HGGOO#
```

Тюремщик — нейтральный босс с 14 HP в E3 и единственная отмеченная цель. Его щит смотрит вниз и запрещает вход спереди. После попытки тяжёлого удара (2 урона), в том числе промаха, он отдыхает один ход с опущенным щитом. Обход с фланга остаётся возможным при поднятом щите.

Рычаг C5 открывает D2, D3, D4 и D5 после цепи: уводит четырёх рядовых врагов, но на следующий ход перекрывает прямую дорогу. Тюремщик не является целью провалов этой расстановки; общее правило движка сохраняет его иммунитет к падению. Жаровня E4 усиливает только остаток текущей цепи. Ни устройство, ни прыжок не обязательны.

Комбинированный маршрут заканчивается с 5 HP за четыре хода:

1. B5 → C5 → C4 → B4 → B3 → C3 → C2. Рычаг открывает полосу, цепь приносит 3 энергии, тяжёлый удар промахивается.
2. Прыжок на E2 за 2 заработанной энергии. После этого хода настил закрывается.
3. F1 → G1 → G2 → F2 → G3 → G4 → F4 → E4 → F3 → E3. Заход к боссу сбоку; физический удар оставляет 5 HP, жаровня снижает остаток до 4 HP.
4. Прыжок на E3 добивает босса во время отдыха.

Быстрый маршрут обходится без устройств и способностей, заканчивается с 3 HP за два хода:

1. B5 → B4 → C4 → B3 → A2 → B2 → C3 → C2 → D1 → C1 → D2 → E3. Босс получает 12 урона, кот остаётся в D2 и принимает тяжёлый удар на 2 HP.
2. D3 → E3. Оставшиеся 2 HP босса снимаются во время его отдыха.

Эти решения показывают осмысленный выбор между сохранением здоровья, длиной цепи и скоростью. Рычаг не убивает босса и не является обязательной головоломкой.

## 15. Через ворота

```text
##RRBBB
RRRXBBB
#RRRBBB
#RRRBVV
#RRRBVV
#HGGOO#
```

Настоящее условие завершения — физически пройти цепью через дверь G1. После первого совершённого хода дверь становится доступна, но сама выполненная цель `turns: 1` победу не даёт (`completion: 'exit'`). Список отмеченных целей пуст. В D2 стоит красный караульный с 3 HP, в F2 — синий стрелок с 3 HP.

Проверенный выход за два хода с 5 HP:

1. B5 → B4 → C4 → C3 → D3 → D2.
2. E2 → F1 → G1.

Кот действительно заканчивает на клетке двери. Стрелок и другие противники остаются на поле: бой не требует уничтожения караула.

## 16. Заставить колокол замолчать

```text
##RRBBB
RRRRXBB
#RRRBBB
#RRRBVV
#RRRBVV
#HGGOO#
```

Нейтральный источник в E2 имеет 8 HP и является единственной отмеченной целью. Каждые два незамороженных ответа он может вызвать до двух вооружённых обычных гоблинов, заменяя объявленных заранее врагов: живых спокойных одноклеточных обычных ближнего боя без варианта (или стул) с 0 HP, без щита и ключа, не под котом и не на устройстве. Призыв привязан к их ID: уничтоженная или занятая заново клетка не является прежней целью. Новоприбывшие не атакуют в фазу своего появления. Уничтожение источника прекращает его призыв; оставшуюся свиту добивать не требуется.

Маршрут с демонстрацией подкрепления, три хода и 5 HP:

1. B5 → B4 → C4 → C3. Накоплены 2 энергии, показаны цели будущего призыва.
2. B3 → B2 → C2 → D2 → E2. Источник остаётся с 3 HP, появляются два вооружённых гоблина.
3. Прыжок на E2. Источник уничтожен, бой завершается при живой вооружённой свите.

Длинная цепь может опередить источник и закончить бой за один ход с 5 HP: B5 → B4 → C4 → C3 → B3 → B2 → C2 → D1 → D2 → E2. Это допустимое решение, использующее освоенное накопление силы.

## Южные альтернативы через новые цвета

Все три варианта начинаются двумя ходами: зелёная цепь `C6 → D6`, затем охристая `E6 → F6`. Они дают 2 энергии. Дальнейшие маршруты заканчиваются с 5 HP:

- **Тюремщик:** фиолетовая `F5 → E5`; затем синяя `F4 → G4 → G3 → G2 → G1 → F1 → F2 → F3 → E4 → E3` через жаровню; прыжок на E3 добивает оставшиеся 4 HP. Пять ходов, рычаг не используется.
- **Ворота:** фиолетовая `G5 → F5 → F4 → G4`; затем `G3 → G2 → F2 → F3 → E2 → F1 → G1`. Четыре хода. Сила до F3 позволяет убрать переместившегося стрелка и действительно пересечь дверь.
- **Колокол:** фиолетовая `G5 → F5 → F4 → G4`; затем `G3 → F3 → F2 → G2 → G1 → F1 → E1 → E2`. Четыре хода; синяя цепь побеждает источник после подхода через три новые цветовые группы.

## Проверка

`npx tsx src/game/chapterFinale.spec.ts` проверяет основные и южные альтернативные маршруты через реальные действия движка, без подмены состояния. Для каждого выполнены чистота прогноза, совпадение урона, конечной клетки и победы с исполнением, затем точное сравнение состояния после перезапуска и повторного прохождения. Дополнительно проверены щит/отдых, закрытие маршрутов провалами, заработанная энергия, горение, реальные подкрепления, физический выход, сохранение живых врагов после достижения цели и доступность только выбранной ветки.
