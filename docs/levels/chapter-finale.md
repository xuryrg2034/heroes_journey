# Финал первой главы и развилка

После первых тринадцати боёв идут Тюремщик (14) и выбор одного из двух самостоятельных боёв: «Через ворота» (15) или «Заставить колокол замолчать» (16). После любой ветки интерфейс предлагает лесное испытание. Все шестнадцать боёв доступны напрямую с начального экрана.

Данные — `src/game/lessons/finale.ts`, построитель `authoredLesson` — `src/game/lessonBuilder.ts`. `nextLessonIndices` содержит индексы с нуля: у Тюремщика `[14, 15]`, у обеих веток `[]`. Отсутствующее поле сохраняет линейный переход; `nextTutorial()` не выбирает ветку автоматически. `startTutorialChoice(index)` проверяет победу и список доступных переходов.

## Общие условия

- Пять обычных цветов, 5 HP, 0 начальной энергии, пустой инвентарь. Доступны прыжок и холодный настой; настой не выдаётся.
- Рядовые враги слабые, с 0 HP, но живы до положительного попадания. Неотмеченные враги пассивны, кроме вооружённых (строчная буква).
- Каждая проходимая клетка, кроме кота, занята врагом или дверью. С расстановки есть цепь.
- Пополнение случайно выбирает цвета по весам палитры со всеми пятью цветами. Выжившие не перекрашиваются, повтор с тем же seed и действиями точен.
- Устройств в боях 14–16 нет.

Обозначения: `#` стена, `H` кот, `R G B O V` — пассивные слабые (красный, зелёный, синий, охра, аметист), `r g b o v` — вооружённые слабые, `J` — Тюремщик, `K` — колокол, `D` — ворота, `Q` — караульный с 3 HP, `A` — стрелок. Каждый пункт маршрута — отдельный ход.

## 14. Тюремщик — 7×6

```text
OVVJo##
ROBBBOO
RBB#BOG
GRRVGHG
OGVVRRR
ORRGOVV
```

```text
№ / id / название: 14 / jailer / Тюремщик
Тип боя: босс
Пазл или системный: пазл, 3 хода
Идея одной фразой: ударить с фланга сейчас, синий «омут» под щитом сохранить до окна отдыха, добить с другого фланга
Особый враг: Тюремщик D1, 14 HP, щит вниз, тяжёлый удар 2 по трём клеткам со стороны кота,
  после любой попытки удара — ход отдыха без щита
Роли врагов: босс-щит; правый фланг E1 (вооружённый охристый) с охристой дорожкой F3–F2–G2;
  левый фланг B1–C1 (два аметистовых); синий омут C2–D2–E2–B3–C3–E3 под щитом (6 врагов)
Приёмы композиции: перешеек (фланги по одной клетке, столб D3), топливо с нужной стороны,
  приманка (омут — самая длинная цепь первого хода)
Главное решение: A — правый фланг (4–5 урона), омут в окно отдыха (7 урона), левый фланг цепью (3 урона);
  B — съесть омут сразу: щит его не пропускает, урона нет, окно отдыха пропадает
Ловушка и предупреждение: цепь по омуту на первом ходу не может закончиться на Тюремщике
  (прогноз: «Щит закрывает этот подход»)
Цель: Тюремщик (`bossKills: 1`, единственная отмеченная цель)
Палитра: 5 цветов; аметист — группы B1–C1, D4–C5–D5, F6–G6
Инструменты: прыжок не нужен; после двух ходов им тоже можно добить
Целевые метрики: minTurns ≥ 3, abilities.requires = false, greedy ≤ 0,35, trapShare 0,4–0,85,
  медиана HP жадного при победе 2–4
```

На старте ни одна цепь не достаёт до Тюремщика больше чем на 5 урона: с правого фланга ведут три-четыре охристых врага, левый фланг от кота далеко, омут снизу закрыт щитом. Стартовые клетки за два хода дают не больше 12 урона; анализатор ни на одном из трёх seed не нашёл победы за 2 хода.

Проверенный маршрут, 3 хода, 5 HP, без прыжка:

1. `F3 → F2 → E1 → D1` — 4 урона (14 → 10). Тяжёлый удар объявлен по C2–E2: кот начинал ниже и правее, поэтому удар бьёт мимо. Тюремщик отдыхает, щит опущен.
2. `E2 → E3 → D2 → C3 → B3 → C2 → D1` — омут снизу в окно отдыха даёт 7 урона (10 → 3). Щит возвращается, следующий тяжёлый удар нацелен на кота в C2.
3. `B1 → C1 → D1` — левый фланг, вход сбоку при поднятом щите: 3 урона, победа до ответа.

Альтернатива: `F3 → G2 → F2 → E1 → D1` (5 урона), тот же омут (9 → 2) и прыжок на D1 — прыжок щит не замечает. Выгоды по сравнению с цепью он не даёт (анализатор: `benefit` 0). Оба маршрута используют только стартовые клетки и проверены на seed урока и пяти подменённых seed пополнения.

Ловушка: `E3 → E2 → D2 → C2 → B3 → C3` на первом ходу. Это самая длинная цепь, её выбирает жадный агент. Тюремщик остаётся с 14 HP, а в окно отдыха для seed урока ни одна цепь не снимает и 7 HP.

## 15. Через ворота — 5×7

```text
#RDB#
GRQBO
GABBO
BBRGG
OBRRG
OVVRB
#VHB#
```

```text
№ / id / название: 15 / escape / Через ворота
Тип боя: передышка
Пазл или системный: пазл, 2 хода
Идея одной фразой: уйти, а не убивать; караул необязателен
Роли врагов: выход C1; караульный C2 (красный, 3 HP, вооружён) у самых ворот; стрелок B3 (синий, 3 HP) держит прямую линию
Приёмы композиции: выход, жадность (караульный рядом с дверью), линия стрелка
Главное решение: дойти до ворот обходом или прорубиться через караул
Ловушка: нет (передышка); стоять на линии стрелка стоит 1 HP
Цель: `turns: 1`, `completion: 'exit'` — после первого хода ворота открыты, победа — войти в них цепью
Палитра: 5 цветов; аметист — группа B6–C6–B7
Целевые метрики: случайный агент ≥ 0,4, minTurns 2, trapShare ≤ 0,3
```

Проверенный маршрут, 2 хода, 5 HP:

1. `D6 → C5 → D5 → C4`. Ворота C1 меняют состояние с «Выполни цели» на «Выход открыт», но сам ход победы не даёт.
2. `C3 → D3 → D2 → D1 → C1` — синяя цепь входит в ворота. Кот действительно стоит на C1, караульный C2 остаётся на поле.

С 30.09.2026 выстрел стрелка бьёт всех существ на объявленной линии: первым ходом стрелок B3 стреляет по B4–B6 и убивает слабых гоблинов там (с 30.09.2026 эти убийства игроку не засчитываются). Их клетки пополняются случайными цветами, поэтому прежний второй ход `B4 → B5 → A4 → B3 → …` через стрелка больше не гарантирован; проверочный маршрут обходит эту линию. Карта и смысл боя не менялись: передышка, стрелок и караульный необязательны.

Маршрут проверен на seed урока и пяти подменённых seed пополнения.

Перепроверка анализатором 30.09.2026 (`npm run analyze:levels -- --lesson 10,15`, параметры по умолчанию): minTurns 2, HP 5, лучших первых действий 3 / 16, trapShare 0,06, P(R) 0,5, P(G1) 1 — жадный агент по-прежнему всегда побеждает, как и задумано для передышки.

## 16. Заставить колокол замолчать — 6×7

```text
KRRROO
#RGGOO
##RRBO
VG##BO
VGOGBO
O#OVBG
BVVVBH
```

```text
№ / id / название: 16 / beacon / Заставить колокол замолчать
Тип боя: экзамен-альтернатива
Пазл или системный: пазл, 3 хода
Идея одной фразой: гонка с подкреплением — оборвать призыв, убив объявленных, или принять удар
Особый враг: колокол A1, 8 HP, не атакует; каждый второй активный ход вооружает двух объявленных гоблинов
Роли врагов: источник в углу с двумя входами B1 и B2 (A2 — стена); красная группа B1–C1–D1–B2–C3–D3;
  объявленные B1 и C1 (первые спокойные слабые по порядку клеток); охристая приманка справа
Приёмы композиции: разгонная полоса (синяя E7–E3), порядок целей (объявленные гоблины), позиция на следующий ход
Главное решение: A — длинная ветвь D3 → C3 → B2 → C1 → B1 → колокол: 6 урона, объявленные гибнут, призыв сорван;
  B — короткая D3 → C3 → B2 → колокол: 4 урона, B1 и C1 вооружаются, B1 бьёт кота в B2
Ловушка: после ветви B цепью колокол в этот ход не добить; остаются прыжок или удар подкрепления
Цель: колокол (`bossKills: 1`); оставшуюся свиту добивать не нужно
Палитра: 5 цветов; аметист — группы A4–A5 и D6–B7–C7–D7
Инструменты: прыжок не нужен; в ветви B он спасает от удара
Целевые метрики: minTurns 2–3, abilities.requires = false, greedy ≤ 0,5, trapShare ≥ 0,3
```

На старте кот далеко от колокола, первой цепью его не достать. Красная цепь к колоколу даёт не больше 6 урона. Самая длинная красная цепь D3 → C3 → B2 → B1 → C1 → D1 проходит все шесть красных и заканчивается не у колокола, поэтому жадный агент ею колокол не ранит.

Проверенный маршрут A, 3 хода, 5 HP, без прыжка:

1. `E7 → E6 → E5 → E4 → E3` — колокол объявляет B1 и C1.
2. `D3 → C3 → B2 → C1 → B1 → A1` — 6 урона (8 → 2). Объявленные гоблины погибли, их клетки пополнены новыми ID, подкрепление не появляется.
3. `B2 → A1` — через второй вход, победа.

Маршрут B (принять призыв):

1. Тот же первый ход.
2. `D3 → C3 → B2 → A1` — 4 урона (8 → 4). В ответ B1 и C1 вооружаются; B1 объявляет удар по B2, где стоит кот. Ни одна цепь в этот ход колокол не добивает.
3. Прыжок на A1 добивает колокол. Если вместо этого остаться, B1 снимает 1 HP.

Оба маршрута используют только стартовые клетки и проверены на seed урока и пяти подменённых seed пополнения.

Прежние бои 14 и 16 выигрывались первым ходом одной длинной цепью. Теперь щит, окно отдыха и призыв участвуют в каждом решении. Прыжок ни в одном из них не обязателен (`restricted.abilities.requires = false`, `benefit` 0).

Вне целевых диапазонов:

- **Бой 14, `trapShare` 0,94** (цель 0,4–0,85). Выигрывающие первые ходы — только две цепи к правому флангу. Все варианты поедания омута и неполные фланговые цепи проигрывают. Попытки расширить решение проверены анализатором и отклонены:
  - сильный левый фланг из пяти аметистовых даёт `trapShare` 0,65, но жадный агент побеждает на 3 seed из 3;
  - третий охристый путь (G3 или F1) даёт 6 урона первым ходом: на части seed появляется победа за 2 хода, жадный — 2/3;
  - поле 7×5 без нижних рядов — `trapShare` 0,93.
- **Бой 14, медиана HP жадного агента при победе 5** (цель 2–4). Жадный агент побеждает на одном seed из трёх, на 11-м ходу; медиана посчитана по одной победе.
- **Бой 16, `firstMoveWinShare` 0,67**, у жадного одна победа из трёх за 3 хода с 5 HP (seed 2). Требования карточки (greedy ≤ 0,5, trapShare ≥ 0,3) выполнены.
- **Бой 15:** жадный агент побеждает всегда. Для передышки это цель (≥ 0,7).

## Проверка

`src/game/chapterFinale.spec.ts` (`npm run test:chapter-finale`) проходит карты через публичные команды движка. Для каждого действия проверяются:

- чистота прогноза;
- совпадение урона, конечной клетки, гибели и победы с исполнением;
- сохранение цвета выживших и палитра новых врагов.

Проверяемые сценарии:

- **Тюремщик:** предел урона первым ходом; щит снизу; окно отдыха после промаха; возврат щита с ударом, нацеленным на кота; добивание цепью с левого фланга; альтернатива прыжком; ловушка с омутом на первом ходу.
- **Ворота:** закрытые, затем открытые ворота; реальный вход в C1; караульный остаётся на поле.
- **Колокол:** объявление B1 и C1; отмена призыва убийством объявленных и добивание цепью через второй вход; короткая ветвь — вооружение B1 и C1, удар по коту в B2, невозможность добить цепью, прыжок.
- **Развилка:** доступна только после победы, обе ветки финальные.
- **Общее:** основные маршруты на пяти подменённых seed пополнения; точный повтор после перезапуска.

Правила щита, отдыха, призыва и отмены устаревшего хода на тестовом поле проверяет `src/game/jailerRules.spec.ts`. Браузерный `tests/finale.spec.ts` при 1280×720 проходит мышью:

- Тюремщика цепным маршрутом и прыжковой альтернативой;
- выбор ветки;
- настоящий выход через ворота;
- объявленный и исполненный призыв колокола рядом с котом;
- переход к лесу.
