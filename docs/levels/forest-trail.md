# Лесная тропа: бои 4–6

Продолжение трёх базовых уроков реализовано в `tutorialLevels.ts` и использует тот же `startTutorial`/`nextTutorial`. В интерфейсе это отдельный отрезок «Лесная тропа». Все карты двухцветные, со случайным пополнением по весам палитры, бесплатным точным повтором и целью по ID отмеченных охранников. Урон ловушки и горение засчитывают поражение цели. Не требуется убивать случайное пополнение.

Карты ниже показывают авторское начальное поле. Маршруты — проверенные примеры для текущего seed и указанного порядка действий. Пополнение не привязано к координатам; одинаковый повтор воспроизводит его через состояние RNG. Выжившие враги не перекрашиваются.

Обозначения: `#` стена, `H` кот, `R/B` слабые красные/синие с 0 HP, `X/Y` отмеченные красный/синий охранники, `L` рычаг стрел, `F` жаровня. Устройства занимают собственную клетку без врага. Подробные [правила устройств](../devices.md).

## 4. Чужие стрелы — 6×6

```text
##RRBB
RRRBYB
#RRRBB
#RLRBB
#HRRBB
##RRBB
```

Кот B5. Рычаг C4: два заряда, 4 урона по A2–F2 после цепи. Синий охранник E2 имеет 8 HP. Остальные враги пассивны.

Проверочный маршрут: `B4 → C4 → D4` включает ловушку и оставляет кота вне линии; охраннику остаётся 4 HP. Затем `E4 → F4 → F3 → E2` набирает 4 силы и добивает его. Рычаг между врагами не меняет цвет и не даёт дополнительную силу.

Альтернатива после первого залпа: `C3 → B3 → C4` возвращается к рычагу и расходует второй заряд. Можно также ранить и добить охранника без ловушки. Это бой на выбор инструмента, а не обязательная последовательность нажатий.

## 5. Угли в топоре — 6×6

```text
##RRBB
RRRBYB
#RBXBB
#RFBBB
#HRBBB
##RRBB
```

Кот B5. Жаровня C4: два заряда. Охранники D3 красный 3 HP и E2 синий 5 HP. `B4 → C4 → D3` наносит 2 физического урона и 1 горение; кот остаётся у жаровни, по диагонали от врага. Охранник погибает на тике в конце хода. Цвет нового врага на D3 выбирается случайно из красного и синего.

Пример повторного применения при текущем seed: `D4 → E4`, затем `D4 → C3 → C4 → D3 → E2`. После этих действий новые D4 и D3 оказались синими; при другом пополнении подход нужно пересмотреть. Четыре врага дают 4 силы; оставшийся 1 HP снимает горение. Огненный эффект действует только после посещения жаровни и только в текущей цепи.

Более быстрое альтернативное решение после первого охранника: `D4 → E4 → F4 → F3 → E2`. Пять силы убивают без второго заряда. Такое решение принимается; самостоятельное сочетание огня с другим устройством ожидает в следующем бою.

## 6. Перекрёстный огонь — 7×6

```text
##RRBB#
RRRXBBB
#RRRBYB
#RRRFBB
#RLRBBB
#HRRBB#
```

Кот B6. Рычаг C5: два заряда, 4 урона по A2–G2. Жаровня E4: два заряда. Охранники D2 красный 8 HP и F3 синий 4 HP.

Один безопасный план:

1. `B5 → C5 → D5`: стрелы оставляют красному охраннику 4 HP.
2. `E5 → F5 → E4 → F3`: 3 силы и горение добивают синего, кот остаётся у жаровни по диагонали от него.
3. `D4 → D3 → C3 → D2`: накопленные 4 силы добивают красного.

Порядок не задан движком. Синего можно взять четырьмя синими целями без жаровни; красного — несколькими физическими подходами без рычага. Цель — спланировать свои действия, а не повторить показанный ответ.

## Проверка

`npm run test:tutorial` проверяет все шесть карт, эталонные маршруты, альтернативное убийство без второго огня, соответствие входящего урона прогнозу, точный повтор, ограничения предметов/способностей и продолжение после разных стартовых остановок. `tests/tutorial.spec.ts` проверяет переходы, реальные цепи мышью и мобильный ввод. Результаты текущего прогона записываются после интеграции.
