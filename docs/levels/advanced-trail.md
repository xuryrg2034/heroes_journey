# К опушке: бои 7–10

Четыре авторских боя продолжают первые шесть и постепенно подводят к отдельному лесному испытанию. Они используют общий движок: никаких специальных формул холода, прыжка или обменов нет. Все карты начинаются с 5 HP и 0 энергии; повтор восстанавливает состояние целиком. Цель каждого боя — два исходных отмеченных противника, даже если один переместился.

## Открытие инструментов

| Бои | Разрешено | Стартовый запас |
| --- | --- | --- |
| 1–6 | Только цепи и устройства карты | Без расходников, способности закрыты |
| 7 | Добавляется холод | Один флакон, прыжок ещё закрыт |
| 8–10 | Добавляется прыжок | Энергия 0; расходников нет |

Холод остаётся изученным и разрешённым в 8–10, но новый запас не выдаётся. Круговой удар, бомба, лечение и огненная склянка пока закрыты. Разрешения проверяются движком и прогнозом, а не только скрытием кнопок. Для учебных боёв нет переноса ресурсов между уровнями.

Обозначения карт: `#` стена, `H` кот, `R/B/G` слабые красные/синие/зелёные, `X/Y/Z` отмеченные цели тех же цветов, `P` огонёк смены цвета. Обычные враги пассивны; отмеченные охранники атакуют по обычным правилам. Начальные расстановки авторские. Пополнение выбирает случайные цвета по весам палитры: в боях 7–8 доступны два цвета, в 9–10 — три. Выжившие не перекрашиваются.

Карты ниже показывают только начало боя. Маршруты — примеры для текущего seed и указанной последовательности действий. Повтор восстанавливает RNG и воспроизводит пополнение при одинаковых действиях; оно не закреплено за координатами.

## 7. Холодная переправа — 5×5

```text
#RRB#
#RRBY
#RXBB
#RRBB
#HR#B
```

Знакомая форма второго урока теперь меняет решение: красный C3 стоит в луже и имеет 6 HP, синий E2 — 4 HP. Один холодный настой замораживает только мокрую цель, пропускает её ближайшее действие и даёт хрупкость для двойного следующего физического удара. Применение не завершает ход; после него проводится цепь.

Проверенный маршрут: холод на C3 → `B4 → C4 → C3` (3 силы дают удар 6) → `D4 → E4 → E3 → E2`. Победа с 5 HP.

Альтернатива без флакона: `B4 → C4 → B3 → B2 → C2 → C3` собирает 6 силы; затем та же синяя цепь. Настой экономит длину подхода, а не является искусственным ключом к победе.

## 8. Через пролом — 6×6

```text
##RBBB
##RBBB
RRR#BB
RXR#YB
HRR#BB
RRR#BB
```

Два охранника по 4 HP: красный B4 и синий E4. Обвал закрывает прямую цепь между берегами. Теперь видны энергия и кнопка прыжка; круговой удар скрыт и запрещён.

`A4 → A3 → B3 → B4` побеждает ближнего охранника и даёт ровно 2 энергии. Прыжок на E4 пересекает стену, наносит фиксированные 4 урона и завершает бой с 5 HP. Прыжок не использует запас обычной цепи и не даёт энергию за своё попадание.

Альтернатива после первой цепи: `C4 → C3 → C2`, затем `D2 → E2 → F3 → F4 → E4`. Северный обход длиннее, но позволяет выиграть без способности. Отдых также сохраняет обычное правило получения 0,5 энергии.

## 9. Три знамени — 6×6

```text
##BBGG
RRRBYG
#RRPBG
#RRBGG
#HRBGG
##BBZG
```

Вводятся третий цвет и заранее размещённый огонёк D3. Синий E2 имеет 8 HP, зелёный E6 — 4 HP. Начать с огонька нельзя; его посещение разрешает сменить цвет, сохраняя запас силы без добавления +1. Его сбор не считается убийством охранника.

Проверенный путь: `B4 → C4 → C3 → B3 → B2 → C2 → D3 → D2 → E2`. Шесть красных дают 6, огонёк сохраняет 6, два синих дают суммарно 8. Затем `F2 → F3 → E4 → E5 → E6` завершает бой с 5 HP.

Можно сначала перейти через огонёк к зелёному: `B4 → C4 → C3 → D3 → E4 → E5 → E6`. Далее `D6 → C6 → D5 → D4 → E3 → D2 → E2` ранит синего до 1 HP; `D1 → E2` добивает через сохранившегося синего врага. Этот проверенный вариант заканчивается с 4 HP. Один из маршрутов быстрее или безопаснее, но оба принимаются.

Огонёк здесь авторский, одноразовый. Автоматическая выдача новых огоньков за длинные цепи в режиме начальных боёв остаётся отключена.

## 10. Передышка стрелка — 6×6

```text
##BBGG
RRRBYG
#RRBBG
#RRBGG
#HRBGG
##BBZG
```

Теперь синий E2 — стрелок с 4 HP, зелёный E6 — охранник с 4 HP. Здоровье стрелка намеренно ниже обычных 7 HP: новое решение связано с выстрелом, отдыхом и обменом, а не с длиной разгона. Начальная линия стрелка — E3–E5.

1. `B4 → C4 → C3` заканчивается вне выстрела. Стрелок стреляет, затем отдыхает и объявляет обмен E2 ↔ D2.
2. `B3 → B2 → C2` сохраняет пару: обмен действительно выполняется, стрелок оказывается D2 и готовит следующий выстрел.
3. `D3 → E3 → E2 → D2` побеждает переместившегося стрелка. Цель считается по его ID.
4. `E1 → F2 → F3 → F4 → E5 → E6` заканчивает бой с 5 HP.

Альтернатива после первого хода: `D3 → D2` заканчивается на клетке обмена и отменяет его. Прыжок E2 убирает стрелка; `F2 → F3 → E4 → E5 → E6` завершает бой. Само убийство участника не отменяет обмен: его место занимает пополнение. Отмена требует кота на одном из концов пары либо живого замороженного участника.

После десятого боя следующий экран предлагает [три боя с провалами](pit-trail.md). После тринадцатого — [Тюремщик и развилка](chapter-finale.md). Палитра расширяется до четырёх цветов в боях 12–13 и до пяти в 14–16. Лесное испытание доступно после любой финальной ветки.
