# «Тюремщик» — контрольный бой карты леса

Бой узла `jailer` (ряд 9, тип «контрольный») [карты леса](../biomes/forest-map.md): сюда сходятся обе тропы, отсюда начинаются ветки к Троллю и Главарю. Победа открывает круговой удар до конца похода (`rewardGrants`). Данные — `src/game/run/battles/shared.ts` (массив `SHARED_BATTLES`, id `jailer-gate`, построитель `authoredLesson`). Карта и seed перенесены 30.09.2026 без изменений из удалённой автономной цепочки уроков «Начало пути» (там это был бой 14).

## Условия боя в походе

- **Ряд 9:** нарастающая злость ([GDD 2.6](../gdd.md#26-поведение-врагов-между-ходами)), пассивности нет. Тюремщик (`variant: 'jailer'`) пассивным не бывает никогда.
- **Палитра пополнения** — палитра ряда 9, пять цветов; стартовая расстановка тоже пятицветная.
- **Инструменты** на входе на любом пути: холод и прыжок. Круговой удар в этом бою ещё закрыт — его открывает победа. HP, энергия и предметы — перенесённые из похода.
- **Цель** — `bossKills: 1`; Тюремщик — единственная отмеченная цель. Кристаллы смены цвета на него не падают (босс).
- Устройств нет.

## Карта

```text
    A B C D E F G
1   O V V J o # #        J — Тюремщик, 14 HP
2   R O B B B O O        o — вооружённый охристый гоблин E1
3   R B B # B O G
4   G R R V G H G
5   O G V V R R R
6   O R R G O V V
```

Обозначения: `#` стена, `H` кот, `R G B O V` — слабые враги (0 HP) цветов киноварь, мох, лазурь, охра, аметист; `o` — вооружённый слабый.

```text
id / название: jailer-gate / Тюремщик
Тип боя: босс (контрольный бой карты)
Пазл или системный: пазл, 3 хода
Идея одной фразой: ударить с фланга сейчас, синий «омут» под щитом сохранить до окна отдыха, добить с другого фланга
Особый враг: Тюремщик D1, 14 HP, щит вниз, тяжёлый удар 2 по трём клеткам со стороны кота,
  после любой попытки удара — ход отдыха без щита
Роли врагов: босс-щит; правый фланг E1 (вооружённый охристый) с охристой дорожкой F3–F2–G2;
  левый фланг B1–C1 (два аметистовых); синий омут C2–D2–E2–B3–C3–E3 под щитом (6 врагов)
Приёмы композиции: перешеек (фланги по одной клетке, столб D3), топливо с нужной стороны,
  приманка (омут — самая длинная цепь первого хода)
Главное решение: A — правый фланг (4–5 урона), омут в окно отдыха (7 урона), левый фланг цепью (3 урона);
  B — съесть омут сразу: щит его не пропускает, урона нет, окно отдыха пропадает
Ловушка и предупреждение: цепь по омуту на первом ходу не может закончиться на Тюремщике
  (прогноз: «Щит закрывает этот подход»)
Цель: Тюремщик
Инструменты: холод, прыжок; прыжок не нужен, после двух ходов им тоже можно добить
Целевые метрики: minTurns ≥ 3, abilities.requires = false, greedy ≤ 0,35, trapShare 0,4–0,85,
  медиана HP жадного при победе 2–4
```

На старте ни одна цепь не снимает с Тюремщика больше 5 HP: с правого фланга ведут три-четыре охристых врага, левый фланг от кота далеко, омут снизу закрыт щитом.

**Проверенный маршрут**, 3 хода, 5 HP, без прыжка:

1. `F3 → F2 → E1 → D1` — 4 урона (14 → 10). Тяжёлый удар объявлен по C2–E2: кот начинал ниже и правее, поэтому удар бьёт мимо. Тюремщик отдыхает, щит опущен.
2. `E2 → E3 → D2 → C3 → B3 → C2 → D1` — омут снизу в окно отдыха даёт 7 урона (10 → 3). Щит возвращается, следующий тяжёлый удар нацелен на кота в C2.
3. `B1 → C1 → D1` — левый фланг, вход сбоку при поднятом щите: 3 урона, победа до ответа.

**Альтернатива:** `F3 → G2 → F2 → E1 → D1` (5 урона), тот же омут (9 → 2) и прыжок на D1 — прыжок щит не замечает.

Оба маршрута используют только стартовые клетки.

**Ловушка:** `E3 → E2 → D2 → C2 → B3 → C3` на первом ходу — самая длинная цепь. Тюремщик остаётся с 14 HP и опускает щит, но в окно отдыха на авторском seed ни одна цепь не снимает с него 7 HP.

## Проверки

`src/game/sharedBattles.spec.ts` (`npm run test:shared-battles`) запускает бой как узел `jailer` (`startNodeBattle` из `src/game/testing/fixtures.ts`: 5/5 HP, 0 энергии, без предметов, холод и прыжок открыты, палитра ряда, нарастающая злость) и проверяет реальными командами:
- расстановку, отмеченную цель по ID, снятие пассивности на ряду 9, непассивное пополнение в палитре узла;
- предел урона первым ходом, запрет входа снизу при поднятом щите;
- окно отдыха после промаха, возврат щита с ударом, нацеленным на кота, добивание цепью с левого фланга;
- альтернативу прыжком и ловушку с омутом на первом ходу;
- основной и прыжковый маршруты на авторском seed и на пяти подменённых seed пополнения;
- совпадение урона, конечной клетки, гибели и победы с прогнозом, чистоту прогноза, точный повтор после перезапуска.

Правила щита и отдыха на тестовом поле проверяет `src/game/jailerRules.spec.ts` (`npm run test:jailer-rules`).

## Метрики анализатора (история, урок начала пути)

Снимок 29.09.2026 для этой карты в прежних условиях автономного урока 14: пассивные неотмеченные рядовые, палитра пополнения из пяти цветов, открыт только прыжок, команда `npm run analyze:levels -- --lesson 11,12,13,14,15,16` (флага `--lesson` больше нет), параметры по умолчанию (`depth 3`, `beam 3`, `budget 400`, 3 seed, 10 × 3 прогонов случайного агента). Прыжок не обязателен (`restricted.abilities.requires = false`, `benefit` 0).

Вне целевых диапазонов на ту дату:
- **`trapShare` 0,94** (цель 0,4–0,85). Выигрывающие первые ходы — только две цепи к правому флангу. Отклонённые анализатором варианты: сильный левый фланг из пяти аметистовых (`trapShare` 0,65, но жадный агент побеждает на 3 seed из 3); третий охристый путь G3 или F1 (6 урона первым ходом, на части seed победа за 2 хода); поле 7×5 без нижних рядов (`trapShare` 0,93).
- **Медиана HP жадного агента при победе 5** (цель 2–4): жадный побеждает на одном seed из трёх, на 11-м ходу; медиана посчитана по одной победе.
