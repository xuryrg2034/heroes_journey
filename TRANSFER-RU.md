# Перенос Ashen Oath на другую машину

Это браузерный проект TypeScript + Vite + PixiJS. Godot для запуска не нужен.

1. Распакуйте архив и откройте папку grind_test в редакторе.
2. Установите Node.js с npm. При упаковке (дата не зафиксирована) сборка проверялась с Node.js 20.18.3 и npm 10.8.2. Ограничения версии Node в package.json нет; на машине разработки 2026-09-29 установлен Node.js 22.20.0.
3. Откройте терминал в grind_test и выполните:

   npm ci
   npm run dev

4. Откройте адрес, напечатанный Vite (обычно http://localhost:5173).

Для установки зависимостей нужен интернет. package-lock.json включён для
восстановления тех же версий. node_modules не переносится между машинами.

Проверка сборки:
   npm run build
   npm run preview

В dist/ лежит сборка, сделанная при упаковке; она может отставать от src/ — пересоберите её командой npm run build. Для разработки используйте src/.
Документация: README.md и docs/. Материалы и снимки проверок: artifacts/.

Браузерные тесты при необходимости:
   npx playwright install chromium
   npm test

Архив содержит файлы проекта, включая текущие несохранённые в Git изменения
на диске. Несохранённые буферы редактора и данные браузера в него не входят.
Пользовательские уровни и черновик редактора хранятся в localStorage:
на старой машине выберите уровень и нажмите «Скачать JSON», затем перенесите
JSON и импортируйте его в редакторе на новой машине. Прогресс игры в браузере
тоже хранится отдельно от файлов проекта.

При упаковке (Node.js 20.18.3, дата не зафиксирована) npm run build завершился успешно; на текущие исходники это не переносится.
