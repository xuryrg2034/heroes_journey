# Перенос Ashen Oath на другую машину

Это браузерный проект TypeScript + Vite + PixiJS. Godot для запуска не нужен.

1. Распакуйте архив и откройте папку grind_test в редакторе.
2. Установите Node.js с npm. При упаковке (дата не зафиксирована) сборка проверялась с Node.js 20.18.3 и npm 10.8.2. Ограничения версии Node в package.json нет; на машине разработки 2026-09-29 установлен Node.js 22.20.0.
3. Откройте терминал в grind_test и выполните:

   npm ci
   npm run dev

4. Откройте адрес, напечатанный Vite (обычно http://localhost:5173). Песочница с меню арен и панелью отладки: тот же адрес с ?sandbox=1.

Для установки зависимостей нужен интернет. package-lock.json включён для
восстановления тех же версий. node_modules не переносится между машинами.

Проверка сборки:
   npm run build
   npm run preview

В dist/ может лежать сборка, сделанная при упаковке; она может отставать от src/ — пересоберите её командой npm run build. Для разработки используйте src/.
Документация: README.md и docs/.

Проверки (полный список команд — в README.md):
   npx tsc --noEmit
   npm run test:realtime-sim
   npx playwright install chromium
   npm test

Архив содержит файлы проекта, включая текущие несохранённые изменения на
диске. Данные браузера в него не входят. Поход и параметры панели отладки
хранятся в localStorage браузера отдельно от файлов проекта и на новой машине
начнутся заново. Логи плейтеста dev-сервер пишет в папку playtest-logs/ (она
в .gitignore); при необходимости перенесите её вручную.

Пошаговая игра удалена 11.10.2026. Её код и документы лежат в истории
репозитория под тегом turn-based-final. Архив без истории репозитория их не
содержит.

При упаковке (Node.js 20.18.3, дата не зафиксирована) npm run build завершился успешно; на текущие исходники это не переносится.
