# Арт персонажа: $ARGUMENTS

Генерирует Codex (встроенный `image_gen`). Claude готовит промпт, запускает Codex, проверяет результат и подключает его. Общий порядок вызова — скилл `codex-delegate`.

## 1. Промпт

- Прочитать `docs/character-art-style.md` и 1–2 записи из `artifacts/art-prompts/characters.json` как образец структуры.
- Короткого архетипа от пользователя достаточно. Позу, эмоцию и снаряжение дополнить самостоятельно, архетип не менять, полный промпт у пользователя не запрашивать.
- **Обязательные части:**
  - `Use case: stylized-concept. Production transparent PNG game sprite for Ashen Oath`;
  - одна фигура в полный рост, три четверти спереди, всё внутри кадра;
  - блок стиля: толстый неровный navy-контур, крупные угловатые асимметричные формы, преувеличенные пропорции, плоские цвета и двухступенчатый cel shading, силуэт читается в 64px;
  - палитра из гайда;
  - `GENUINELY TRANSPARENT alpha background, no scenery, no floor, no text`;
  - негативы: `NOT photorealistic / painterly / anime / 3D / glossy`.
- Фон: для игрового ассета — прозрачный (раздел «Игровые ассеты» гайда). Нейтральный светлый фон из базового промпта гайда применяется только к концепту, который пользователь просит отдельно, без подключения в игру.
- Цвет цепи игра рисует плиткой и сигилом под фигурой, поэтому персонажа не окрашивать целиком в цвет цепи.
- Сохранять единый стиль с существующими персонажами. Менять стиль только по прямому указанию пользователя.

## 2. Генерация через Codex

```bash
codex exec -C /Users/xuryrg2034/Projects/Godot/grind_test -s workspace-write \
  -c model_reasoning_effort='"medium"' -o "$S/codex-art-<id>.md" "$(cat "$S/art-<id>-task.md")" \
  </dev/null > "$S/codex-art-<id>.log" 2>&1
```

Запускать в фоне. Текст задачи для Codex (`$S/art-<id>-task.md`):

- Сгенерировать изображение встроенным image_gen по промпту (вставить промпт дословно). До 3 попыток, выбрать лучшую по силуэту и соответствию стилю.
- Сохранить итог как RGBA PNG в `public/art/characters/<id>.png`. Прозрачный фон; если фон получился непрозрачным — удалить его. Обрезать по силуэту с отступом не больше 2%. Размер около 1200–1350 px по большей стороне.
- Добавить запись `{ id, file, generator: "built-in image_gen", prompt }` в `artifacts/art-prompts/<набор>.json`.
- Не менять никакие другие файлы. В отчёте указать путь к исходнику в `~/.codex/generated_images/`.

## 3. Проверка результата (делает Claude)

```bash
node .claude/skills/character-art/scripts/check-art.mjs public/art/characters/<id>.png
```

Скрипт проверяет RGBA, прозрачные углы, отсутствие непрозрачной кромки (обрезанная фигура) и что фигура не занимает весь кадр.

Затем открыть PNG через Read и оценить глазами:

- соответствие архетипу и гайду;
- читаемость силуэта в малом размере;
- отсутствие текста, рамки и нескольких фигур;
- единство со стилем соседних персонажей (сравнить с `player.png` и `melee.png`).

Не устраивает — перезапустить Codex с конкретными правками промпта.

## 4. Подключение (для нового id)

- `src/render/characterAssets.ts`: добавить id в `CHARACTER_ART_IDS`. Выбор иллюстрации идёт по `variant ?? kind` (`characterArtId`).
- Процедурный резерв в `src/render/art.ts` или `castleArt.ts` должен оставаться: при ошибке загрузки фигура рисуется им.
- Проверить в игре через скилл `run` или `claude-in-chrome` при 1280×720:
  - фигура видна и не перекрывает HP, состояние и прогноз;
  - нет ошибок в консоли;
  - при отсутствии файла открывается резерв.
- Документация: раздел о наборе в `docs/character-art-style.md` и ссылка на файл промптов. Результат проверки — с датой (скилл `docs-sync`).
