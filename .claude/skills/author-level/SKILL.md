# Авторский бой: $ARGUMENTS

Прочитать перед правкой: `docs/levels/opening-sequence.md` (кривая), профильный `docs/levels/*.md`, `docs/level-authoring-research.md`, при устройствах — `docs/devices.md`.

## Формат урока (`src/game/tutorialLevels.ts`)

`lesson(id, name, description, hint, rows, seed, goal, armedTargets?)`. Символы карты:

| Символ | Значение |
|---|---|
| `#` | стена |
| `H` | кот (ровно один) |
| `R` `G` `B` `O` `V` | враги цветов 0, 1, 2, 3, 4 |
| `X` / `Y` | отмеченная цель красного / синего цвета |

Все строки одной длины; каждая проходимая клетка, кроме кота, занята. Дополнительно задаются `allowedItems`, `allowedAbilities`, `initialEnergy`, `nextLessonIndices` (нет поля — линейный переход, `[]` — конец главы), устройства и провалы через `definition`.

## Правила из AGENTS.md, которые нельзя нарушать

- **Палитра не сужается:** бои 1–8 — 2 цвета, 9–11 — 3, 12–13 — 4, 14–16 — 5. В лесу и походе — все 5.
- **Стартовая расстановка подготовлена заранее и разноцветна.** Нужный маршрут выделяется планировкой и расположением противников, а не заливкой поля одним цветом.
- **Новые цвета размещаются связанными группами.** Маршруты проверяются реальными ходами.
- **Фиксирована только стартовая расстановка.** Пополнение случайно по seed и весам палитры. Никаких цветовых таблиц по координатам, `refillColors`/`refillCandidates`.
- **Выжившие не перекрашиваются.** Стартовые враги не перекрашиваются и не ослабляются генерацией. Неверная стартовая карта отклоняется целиком (`startTutorial` возвращает `false`).
- Первые шесть уроков сохраняют ограничения на предметы и способности.
- Не менять игровые правила ради удобства заранее выбранного маршрута или простоты теста.

## Проверка маршрута

1. Скрипт в scratchpad: `new ForestEngine()`, `animationScale = 0`, `startTutorial(i)`, затем реальные `beginChain`/`extendChain`/`releaseChain`, сверка с `preview(path)` (`hits`, `power`, `pitCells`, `playerDies`).
2. Задуманное решение проходит; очевидные неверные маршруты не дают победы случайно.
3. После каждого хода: `hasOrdinaryChain(state)` из `boardGeneration.ts` — ход не упирается в тупик.
4. Несколько seed: решение не должно зависеть от удачного пополнения, если урок этого не предполагает.
5. В браузере при 1280×720 (скилл `run` или `claude-in-chrome`): поле, цель, HP/энергия и действия видны на первом экране, подсказка не перегружает экран.

## Обновить

- Тесты: `test:tutorial`, `test:advanced-tutorial`, `test:pit-lessons`, `test:chapter-finale`, `test:tutorial-capabilities`, `test:refill-randomness` — ожидания только там, где изменилось намеренное поведение.
- Документы: профильный `docs/levels/*.md`, `docs/levels/opening-sequence.md`, README (раздел «Проект первых уровней»); если изменилось число или состав боёв — краткая память проекта в `AGENTS.md`.

Для JSON редактора (`customLevel.ts`) веса палитры пользователя сохраняются: нулевой вес исключает цвет, пока его не активирует `extraColors`.
