# Перенос памяти Claude Code на другую машину

Папка хранит память Claude Code о проекте Ashen Oath, снятую 14.10.2026 на старой машине (macOS). Цель — новая машина на Windows 11.

## Что в папке

| Путь | Что это | Куда ставить |
|---|---|---|
| `memory/*.md` | Файлы памяти проекта и индекс `MEMORY.md` | Папка памяти проекта на новой машине |
| `user-skills/council/SKILL.md` | Личный скилл пользователя «council» (совет агентов), не только для этого проекта | `%USERPROFILE%\.claude\skills\council\SKILL.md` |
| `settings.local.json.example` | Разрешение git без запроса (`Bash(git:*)`) | `.claude\settings.local.json` в корне репозитория (файл в `.gitignore`) |

Что НЕ перенесено:
- **Стенограммы сессий** (`*.jsonl`): старые сессии на новой машине продолжить нельзя.
- **`~/.claude/settings.json`**: в нём были настройки прокси старой машины с учётными данными. Настройки новой машины пользователь задаёт сам.

Агенты (`.claude/agents/`), скиллы проекта (`.claude/skills/`) и `AGENTS.md` уже лежат в репозитории, их переносить не надо. Спеки задач, исследования и решения дизайна из черновиков сессии design лежат в `docs/design-notes/`. Сборка артефакта для плейтеста — `tools/artifact/`.

## Промпт для Claude на новой машине

Откройте Claude Code в корне клонированного репозитория и вставьте текст ниже.

```text
Перенеси память Claude Code об этом проекте со старой машины. Всё лежит в .claude/memory-transfer/ этого репозитория (прочитай там README.md).

1. Найди свою папку памяти проекта. Путь указан в твоём системном промпте, в разделе о памяти. Если его там нет, путь такой: %USERPROFILE%\.claude\projects\<полный путь к корню репозитория, где каждый символ, кроме букв и цифр, заменён на «-»>\memory\. Создай папку, если её нет.
2. Если в папке уже есть файлы, сначала покажи их список. Ничего не перезаписывай без моего ответа.
3. Скопируй туда все файлы из .claude/memory-transfer/memory/, включая MEMORY.md. Содержимое не меняй.
4. Скопируй .claude/memory-transfer/user-skills/council/SKILL.md в %USERPROFILE%\.claude\skills\council\SKILL.md.
5. Если файла .claude\settings.local.json нет, создай его из .claude/memory-transfer/settings.local.json.example. Если файл есть, добавь в permissions.allow недостающие правила из примера.
6. Прочитай каждый перенесённый файл памяти и сверь его с этой машиной. Память писали на macOS: там пути /private/tmp/... и ~/.claude/..., переменная HTTP_PROXY, bash-скрипт verify.sh, ссылки node_modules на общую установку. Проверь, что здесь установлены Node, npm, Git Bash или WSL (verify.sh запускается через bash) и что `npx playwright install chromium` выполнен. Если правило из памяти здесь не действует или требует другой команды, допиши в этот файл короткую заметку «Windows 11: …» с датой. Само правило не удаляй.
7. Проверь, что git видит удалённый репозиторий: git -C <корень> remote -v и git -C <корень> fetch.
8. Дай мне короткий отчёт на русском в стиле ASD-STE100: что скопировано и куда, что на этой машине не так, как в памяти, что мне сделать руками (например, SSH-ключ для GitHub, npm ci, настройки Claude Code).
```

## Как обновить снимок

Снимок не обновляется сам. Чтобы перенести память ещё раз, скопируйте папку памяти проекта (`~/.claude/projects/<slug>/memory/`) в `memory/` и закоммитьте изменения.

Репозиторий публичный: не кладите сюда токены, пароли, настройки прокси и личные данные.
