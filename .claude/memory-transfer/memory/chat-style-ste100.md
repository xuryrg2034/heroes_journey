Ответы пользователю в чате пишу так, чтобы примерно 80% текста следовало правилам ASD-STE100 (Simplified Technical English), применённым к русскому языку:
- короткие предложения: инструкция — до 20 слов, описание — до 25;
- одна мысль или одно действие в предложении;
- действительный залог, прямой порядок слов, глагол в повелительном наклонении для инструкций;
- одно слово — одно значение; один и тот же термин для одного понятия во всём ответе;
- без вводных оборотов, метафор и двусмысленных местоимений;
- списки и таблицы для перечней и шагов.

Остальные ~20% — свободный текст там, где нужен разбор или аргументация.

**Why:** пользователь попросил 04.10.2026: «Добавь это правило для ответов, которые приходят мне в чат. 80% писать текст в формате ASD-STE100».
**How to apply:** все ответы в чат этому пользователю, в том числе отчёты и вопросы на решение. Документы проекта (docs/*) и сообщения другим сессиям — по их собственным правилам, если пользователь не скажет иначе.
