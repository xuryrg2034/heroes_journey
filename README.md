# Ashen Oath

Браузерная игра реального времени на TypeScript, Vite и PixiJS. Кот-варвар с топором идёт по карте леса: бои на аренах, привалы, находки, события, торговец. Бой — цепь по цвету. Игрок выделяет цепь одноцветных врагов, пока время замедлено, и герой проходит по ней ударами. Поход заканчивается победой над боссом или поражением на любой арене.

Пошаговая версия игры удалена 11.10.2026 по решению пользователя. Её код и документы хранит тег `turn-based-final`. Посмотреть: `git show turn-based-final:README.md`.

Художественный стандарт новых персонажей — [Character Art Style Guide](docs/character-art-style.md).

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173/.

| Адрес | Что открывает |
| --- | --- |
| `/` | Игра. Первый запуск (нет ключа `ashen-oath-realtime-prologue-done`) — пролог «Опушка» (десять комнат); потом «Новый поход» или карта сохранённого похода |
| `/?seed=N` | Поход с заданным seed (всегда полный стартовый дар, профиль не меняется) |
| `/?prologueRoom=N` | Только dev-сервер (`npm run dev`, тесты), только без ключа «пролог пройден»: пролог сразу с комнаты N (1–10), как после прохода комнат 1…N−1; записи телеметрии пролога нет. В опубликованной сборке параметр не действует |
| `/?sandbox=1` или `/#sandbox` | Песочница: меню арен (клавиши 1–9, 0, Shift+1…), панель отладки, хуки `window.__realtime`. С 15.10.2026 (просьба пользователя) — кнопка «Песочница» в шапке карты похода (слева от «Логи»; только на карте, не в открытом бою) ставит `#sandbox`; в такой песочнице кнопка «Поход» (у «Арены (M)» и «← Поход» в углу меню арен) снимает якорь — тот же поход с карты. У `?sandbox=1` кнопки «Поход» нет |
| `/?sandbox=1&arena=N` | Песочница, сразу арена N |
| `?telemetry=0` | Любой адрес без записи логов |
| `realtime.html` | Перенаправление на корень (адрес запроса и якорь сохраняются) |

Сборка и просмотр:

```sh
npm run build     # tsc --noEmit и vite build
npm run preview
```

## Управление

- **Цепь.** Нажмите на врага в круге вокруг героя и ведите мышь по врагам того же цвета. Следующее звено должно быть в радиусе от предыдущего и на прямой видимости. Пока цепь выделена, мир замедлен. Отпустите кнопку: герой проходит по цепи и бьёт. Esc или правая кнопка отменяет цепь.
- **Глубина звена.** Число у кольца следующего звена — сколько звеньев цепь ещё может взять от него (от 2). Выключается шестерёнкой на карте похода или флажком «Глубина звена» панели отладки.
- **Новое на карте.** Первая встреча вида врага или аффикса элиты в бою похода — подпись на 1,5 с у врага («Волк — окружает; в стае бьёт сильнее»); один раз на зрителя (память — `localStorage`). На карточке доступного узла у арены с ещё не виденным видом стоит «✦ новое»; в походе с расписанием «встречено» читается из истории расписания — и для врагов, и для строки «Местность» (обрыв, вода, терновник; с 15.10.2026). Выключается шестерёнкой на карте («Новое на карте»); песочница ничего не пишет.
- **Подписи у места («Обучение», с 12.10.2026).** Коробки подсказок внизу боя больше нет. В бою похода короткие подписи в мире у предмета: «Пластина — 1 удар» под элитой с бронёй, цена сундука «Заставы» («+1 урон касания, 12 убийств») у сундука, «Закончи цепь здесь» у рычага гоблина. Подпись держится до действия, уходит с ним и не возвращается этому зрителю (`localStorage`). Слоты расходников пульсируют, пока не применён первый предмет (плашки «Предметы: клавиши 1–4» больше нет; мигание только что полученного предмета видно поверх пульса). Строка управления внизу в походе — только клавиши: «WASD идти · ЛКМ цепь · ПКМ/Esc отмена». На экранах похода тихие строки (карта — «Ресурсы — крафт на привале…»; строки котла, зарока и кости — только там, где эти правила включены, в новом походе их нет). Шестерёнка карты: «Подсказки» (подписи, пульс и строки) и «Обучение» (заново показывает подписи и пульс и проходит пролог ещё раз; поход не меняется).
- **Пролог «Опушка» (с 12.10.2026, первый запуск).** Малые комнаты до похода учат цепи делом: «Тропа» (нажать, вести, отпустить), «Два цвета», «Крепкий» (сила цепи — звенья), «Радуга» (смена цвета на 6-м звене), «Гоблин» (закончить цепь на рычаге), «Толпа» (15 убийств, щит цепи, прыжок, Q). С 13.10.2026 (задача 9) комнат девять: 5 «Пропасть» (Пробел и клик за обрыв, дверь за ним открыта), 6 «Вихрь» (шесть врагов кольцом — одним ударом Q), 7 «Зелье» (герой с 5 HP пьёт зелье — клавиша 3 или плитка); «Гоблин» — комната 8. С 13.10.2026 (задача 13) комнат десять: 9 «Щит» — плотная толпа врагов вокруг героя (спят до первого нажатия, как в «Гоблине»); цепь из 3+ убийств даёт щит 0,5 с (как в походе), касание в щит зажигает лампу (одна лампа за щит, «Щит: 3»), кольцо и герой возвращаются, когда щит кончился; с третьей лампой дверь открывается и враги засыпают; цепь из 1–2 щита не даёт — касание ранит; пока щит поднят, герой светится золотом, поглощённое касание даёт искру «блок» на его ободке, к зажжённой лампе летит искра; рука через 1,5 с покоя показывает цепь из 3+ сквозь толпу; «Толпа» — комната 10. В комнатах 5–7 панель действий показывает только свою плитку, и она пульсирует; в «Пропасти» рука показывает клик за обрывом. Над дверью лампы по цели; в комнатах 1–8 на экране только HP и цель (и плитка комнаты); короткие подписи у места («Зажми и веди», «Цвет свободен», «Закончи цепь здесь»); через 4 с без нажатия призрачная рука показывает цепь, а если с места героя цепь не начать — стрелка и мигающий круг. В углу кнопка «Пропустить обучение»; смерть в комнатах 8–10 — та же комната с полным HP, без экрана поражения. В песочнице пролога нет. [docs/realtime-onboarding.md](docs/realtime-onboarding.md).
- **Котомка у двери** (с ряда 2 похода). Цели открыли дверь — рядом стоит мешок с числом «12/20 · +2» и тремя метками. Убийства после целей наполняют три ступени (10, 20, 35 — 1, 2, 3 ресурса). Потеря HP откатывает незаполненную ступень («сброс»). Дверь платит заполненные ступени; экран итога: «Котомка: +3 — 2 Роса, 1 Смола».
- **Лечение на карте (поход, с 14.10.2026, задача 15).** На карте и на карточке боя до «В бой» (любой бой, включая Тюремщика и финал): +2 HP (не выше максимума) за ресурсы — 2 за первую покупку похода, +1 за каждую следующую (2, 3, 4…); платёж как у торговца; бой карточки от лечения не меняется. Нельзя в начатом бою, на экранах события, торговца, привала и после боя, при полном HP, при нехватке ресурсов. Кнопка в шапке у HP: «Лечение +2 HP — 2 ресурса», выключенная — с причиной («HP полное», «Нужно 4, есть 1»); в окне «Бой» — над «В бой». Видна при ≥ 1 ресурсе. Ресурсы в шапке — одно число со значком, виды — в подсказке, на привале, у торговца и в итоге боя. Поход, сохранённый раньше, лечения на карте не имеет ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 3, «Лечение на карте»).
- **Подвиги (поход, с 14.10.2026, задача 16).** Со второго похода (после первого Тюремщика): у обычного боя, «Заставы», прорыва и боя события — необязательный подвиг: «Набери N очков» (800 / 1000 / 1200 по рядам), «Продержись N с после целей» (20 / 30 / 40), «Продержись N с на арене» (60 / 80 / 100). Награда показана заранее: 3–4 ресурса или выбор талисмана из 2; только при выходе в дверь, провал ничего не стоит. Строка на карточке («Подвиг: продержись 20 с после целей → 3 ресурса»), у таймера в бою («Подвиг 12/20 с», выполнен — «Подвиг ✓» и звон), у открытой двери, пока не выполнен, и в итоге боя («Подвиг: +3 — 2 Роса, 1 Смола»). У Тюремщика и финала подвига нет ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 3, «Подвиги»).
- **Звук.** Вне песочницы (поход и пролог) — «Звук» и «Громкость» в шестерёнке на карте похода (по умолчанию включён, 0,3). Настройка — в `localStorage` зрителя, не в журнале. Песочница звучит по своей панели («Звук удара»).
- **Тряска и вспышки.** Список в шестерёнке на карте похода и в разделе «Вид» панели песочницы: 100 / 50 / 0 %. Множитель на тряску арены и вспышку на весь экран; при 0 % их нет; вспышек на весь экран — не больше 3 в секунду. Настройка — в `localStorage` зрителя, не в журнале.
- **Мета v1 (задачи 36–37).** Экран конца похода: опыт героя с разбивкой и полосой до следующего порога, открытие набора — три карточки переворачиваются, новый рекорд глубины, «В лагерь: +N». Лагерь «Очаг»: костёр, запас, Неясыть, Марфа и Ерофей с репликами и улучшениями, бестиарий, выбор из 2–3 карт леса в начале похода. Подробно — [docs/realtime-slice.md](docs/realtime-slice.md), раздел 14.
- **Сочность (задача 35).** Убитый враг рассыпается осколками своего цвета: 4 у первого звена цепи, 8 с шестого. Ресурсы, пришедшие на экране похода, летят к числу в шапке, число тикает вверх. «Тяжёлый клинок» делает линию цепи шире со стальным сердечником и удар ниже, со стуком; «Пятое звено» ставит золотую засечку у звена, где сработает, и звенит колокольчиком.
- **Часы сессии.** Экран конца похода пишет «В игре 47 мин · походов 2». После 90 минут игры без перерыва в 10+ минут на карте (не в бою) появляется одна тихая строка «Хорошее место остановиться — поход сохранён», не чаще раза в 90 минут. Окон и блокировок нет. Выключается шестерёнкой на карте похода («Часы сессии»). Данные — в `localStorage` зрителя, не в журнале.
- **Конец похода.** Экран конца пишет факты по порядку: кто сразил героя, ряд и сколько рядов до «Последнего рубежа», пройден ли Тюремщик, лучшая цепь похода. Победа — только финальный ряд и лучшая цепь ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 9, П6).
- **Ходьба:** WASD или стрелки.
- **Прыжок:** Пробел, затем клик в точку (стоит энергию). **Круговой удар:** Q.
- **Расходники:** клавиши 1–4 (холод, бомба, лечение, огонь), прицел мышью.
- **Панель действий** (с 13.10.2026) внизу по центру: плитки Пробела, Q и предметов (пустые скрыты). Клик по плитке — как клавиша; прыжок и предмет с точкой ждут клика по полю. Пока цепь рисуется, над героем — число силы (красное, если последний выживет). На карте похода клик по узлу открывает карточку по центру: цель, враги, элиты, местность и «В бой» ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 9, «Интерфейс боя»).
- **P** — пауза. **N** — отметка «здесь что-то не так» (попадает в лог плейтеста). **Enter** — продолжить после арены.
- В песочнице: **M** — меню арен, **R** — перезапуск арены, **`** или F1 — панель отладки.
- **Второе дыхание** (песочница — флажок панели отладки «Второе дыхание (песочница)»). Раз за бой смертельный удар оставляет 3 HP и 2 с неуязвимости; котёл боя обнуляется, клятва боя нарушена ([docs/realtime-prototype.md](docs/realtime-prototype.md), раздел 9н). В походе с «Пологим входом» (с 13.10.2026) — раз за поход, только на рядах 1–4.
- **Тюремщик в походе (задача 28, симуляция и поход с 15.10.2026).** Узел ряда 5 нового похода (флаг сохранения `jailer`; старые сохранения — прежний пул) играет бой Тюремщика — арену «Тюремщик» ниже. Бросок узла поток `pool` не сдвигает. В походе с расписанием это дуга «часть»: пока обрыв не встречен — двор без оврага, пока щитоносец не встречен — ядро без щита. Смерть ядра кончает бой (ключ `bossClears`, и в песочнице): вся толпа гибнет без зачёта игроку, дверь открыта, герой больше не теряет HP; проход, убивший ядро, кончается на нём, подсветка звеньев после ядра — без исхода. Гиря, отрубленная игроком, роняет добычу элиты (`bossPartLoot`, поход), и выбор зарока или реликвии — 1 из 4 вместо 1 из 3. Отчёт: раздел «Босс» ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 7, «Тюремщик в походе»).
- **Гарнизон (задача 38, шаг 1а, с 16.10.2026; в игре включён с v65 — `RT_GARRISON_ON` = true, решение дизайна 16.10.2026).** Новый поход получает флаг `garrison` (`createRtRun(seed, { garrison: false })` — поход без гарнизона, так играют маршруты прежних тестов; старые сохранения без флага кончаются финалом леса) после победы в финале леса не кончается: реликвия на выбор из трёх, «Предместье» (HP до максимума, кнопка «В гарнизон»), затем карта гарнизона — тот же генератор со своей солью, 10 рядов: «Плац» (строй стражников — готовая цепь одного цвета), «Псарня» (псарь держит псов на поводках), «Галерея», «Караульня» на ряду 5 и трудных узлах, Кастелян на ряду 10; победа над Кастеляном — победа похода. Закон связи: отрезок прохода цепи, пересекающий поводок, рубит его после прохода (подсветка показывает тот же поводок красным); сорвавшийся пёс 6 с в ярости кусает всех, его убийства игроку не засчитываются. Кастелян v0 — каркас Тюремщика: бесцветное ядро (4 HP, 4 пластины), два пса на поводках, «Спустить пса», «Караул!»; разрубленный поводок и убитый пёс снимают по пластине. Арены гарнизона — в конце меню песочницы (`?arena=20…24`). Вид: поводок — верёвка цвета хозяина, красная со знаком разреза, когда нарисованная цепь его разрубит, обрыв со звуком после прохода; пёс в ярости — красное зубчатое кольцо; полоса «Спустить пса» и полоса босса Кастеляна; «Предместье» — полоса HP заполняется; карта гарнизона — холодный камень, «Караульня» и «Кастелян» подписаны; шапка называет уровень: «Лес», «Гарнизон»; рекорд глубины — «Гарнизон, ряд N». Арт врагов и фон «Предместья» — дизайна; без картинки — силуэты-заглушки ([docs/realtime-slice.md](docs/realtime-slice.md), «Гарнизон»; [docs/realtime-elite-behaviors.md](docs/realtime-elite-behaviors.md), «Гарнизон»).
- **Тюремщик — каркас босса (песочница — задача 27, симуляция с 15.10.2026; поход — задача 28).** Арена `jailer` («Тюремщик») — двор «Заставы»; ядро Тюремщика (HP 2, на аренах босса с задачи 32 — 5 и бесцветное: его берёт цепь любого цвета, цвет цепи оно не задаёт и в «Смену цвета» не входит; 3 пластины, щит спереди, как у щитоносца) — цель боя, его гиря (HP 3, 1 пластина) — часть босса и звено цепи. Гиря держит «Кистень» (полукруг 2,5 перед ядром, −2) и «Бросок гири» (круг 1 на герое, −2); ядро во второй фазе (1 пластина или 30 с) — «Свисток» (4 врага цвета гири у ворот). Отрубленная гиря — убийство цепи; после прохода ядро теряет пластину, кистень и бросок пропадают, Тюремщик бежит к герою. Арена включает ключи `bossFrame`, `bossClears`, `jailerColorless` и `jailerHp` (5) сама; панель — «Тюремщик: бесцветный», «Тюремщик: HP ядра» 2–10. В меню арен песочницы — «Тюремщик» под своим заголовком (⇧9, `?arena=19`). Вид: ядро — рисунок `jailer.png`, гиря — шар с шипами цвета цепи на серой цепи кистеня; знаки приёмов — штрихованный полукруг «Кистеня», метка «Броска гири», круг «Свистка» у ворот с точками цвета гири; пластины — точки, HP — плашка атамана; подсветка «отрубит» — точка пластины ядра мигает пустым лимонным кольцом; после отрубания цепь рассыпается, над ядром «−1 пластина». Задача 28 (вид): в бою с боссом — полоса босса 480 × 14 px сверху по центру под плашкой HUD (ячейки HP и пластин ядра, черта фазы; гаснет со смертью ядра); первый «Кистень» и первый «Бросок гири» боя называют себя у знака на 1 с; толпа, погибшая с боссом (`bossClears`), умирает волной от ядра. Задача 32 (вид): ядро бесцветное — серый диск и плашка без знака; цепь любого цвета не затемняет ядро; полоса — 5 ячеек HP ([docs/realtime-elite-behaviors.md](docs/realtime-elite-behaviors.md), «Каркас босса и Тюремщик», «Вид»).
- **Пологий вход (поход, с 13.10.2026, задача 17).** Новый поход начинается с зелья лечения; одна новинка на ряд: элиты — с ряда 4 (элита ряда 4 — из уже встреченных обычных, волков, кабанов), аффикс, 3 пластины и крепкие с 3 HP — с ряда 6, «Колючие заросли» (дикобраз) — на рядах 7–8, первая встреча вида — не позже ряда 8 (не встреченный дикобраз в финал не приходит); ряд 1 — только «Поляна» («Двор кнопок» с ряда 2); после удара неуязвимость 1 / 1 / 0,8 / 0,65 с на рядах 1–4 (дальше 0,5 с), касание крепких 2 — с ряда 3; второе дыхание раз за поход на рядах 1–4 (на карте у HP — крылатое сердце: горит, пока ждёт, тусклое, когда потрачено; в бою — «второе дыхание: 3 HP»). Карточка узла пишет таблицы того похода, который играется. Зелье и второе дыхание включаются своими флагами похода (`startPotion`, `secondWind`), таблицы и пулы — флагом `gentleEntry`. Поход, сохранённый раньше, доигрывается по прежним правилам. Поход и пролог не читают сохранённую панель песочницы: поход настраивается только `RT_RUN_FORCED` ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 7, «Пологий вход»).
- **Испытание I–V (поход, с 14.10.2026, задача 18).** После первой победы в походе без заданного seed на «Новом походе» можно выбрать ступень «Испытание: 0 · I · II · III · IV · V» (по умолчанию — последняя выбранная; под выбором — строка ступени). Шапка карты пишет ступень мелко: «Испытание III». Ступени накопительные: I — без стартового зелья и второго дыхания; II — таблицы и пулы рядов до задачи 17 (элиты с ряда 3, шаг брони с ряда 5, «Колючие заросли» на рядах 5–8); III — неуязвимость 0,5 с и касание крепких 2 с ряда 1 (поход v40); IV — 2 аффикса у элит с ряда 6; V — пол плотности ×1,15 во всех боях и фазы финала на 15 % раньше (предел арены прежний). Сохранение — поле `ash` (версия 7), профиль — `won` и `ash` ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 7, «Испытание I–V»).
- **Формы (песочница, задача 29, 15.10.2026; в походе — задача 30, ниже).** В «Сборке» панели отладки — «Форма · конец» (Печать, Прямая), «Форма · звено» (Развилка, Чужак, Близнецы, Якорь у героя), «Форма · путь» (Наледь); молоты — в списке «Молот» с подписью поля. В начале боя значок каждой формы летит от героя к своей строке колонки. Подсветка: «Развилка» — кольца досягаемости у звеньев и знак Y у кандидата от не-последнего звена; «Чужак» — пунктирное кольцо цвета кандидата; «Близнецы» — линия цепи двух цветов; «Наледь» — кольца холода до отпускания и след после; «Возврат» — путь назад пунктиром цвета цепи со стрелками ([docs/realtime-prototype.md](docs/realtime-prototype.md), раздел 9ф, «Вид форм»). Цена форм (задача 33, песочница; поход — без цены до задачи 30): «Близнецы» — после второго цвета пары цвета чередуются (A-A-Б-A-Б), и «Смена цвета» с ними не действует; «Развилка» — одна развилка за цепь (панель «Талисманы»: `twinsAlternate`, `twinsNoShift`, `forkBranches`).
- **Формы в походе (задача 30, 16.10.2026).** Новый поход (флаг сохранения `forms`; старые сохранения — прежние правила) на первом экране Тюремщика предлагает 3 формы полей «Путь» и «Конец» вместо молотов: «Огненный проход», «Режущий проход», «Возврат», «Наледь», «Взрыв на конце», «Прямая», «Печать» (гиря отрублена — 1 из 4). Первый поход (зритель ещё не бился с Тюремщиком) — только «Прямая», «Наледь», «Взрыв на конце». «Застава» после формы даёт в редком месте форму другого поля. Одна форма на поле: новая заменяет прежнюю, карточка пишет «Заменит «…»». В общем пуле талисманов — «Близнецы» (необычный); «Чужак» и «Развилка» в поход не входят. Бои такого похода играют окно счётчиков («Острие», «Улов»), цену «Близнецов» и «Возврат», зафиксированный при отпускании. Подробно — [docs/realtime-slice.md](docs/realtime-slice.md), раздел 8, «Формы в походе».
- **Прямая** (флажок «Прямая (пробой)» в группе «Прямая» панели отладки — только песочница; в походе с задачи 30 — форма «Прямая»). Если хвост цепи из последних 3 врагов почти прямой (каждый поворот до 25°), последнее звено гибнет и сила после него не меньше 1, проход продолжается по линии на 1,875. Каждое тело в коридоре 0,5 получает силу цепи, сила не тратится. Пока цепь рисуется, видны стрела, конец и метки исхода над телами коридора. В походе не действует ([docs/realtime-prototype.md](docs/realtime-prototype.md), раздел 9п).
- **Срез казино-слоя в походе** (12.10.2026). Поход не играет котёл, кость у двери и ставку зарока: в итоге боя нет строки «Котёл», после победы нет экрана кости, карточки узлов не предлагают зароков. Код и песочница остались. Старые сохранения читаются (открытый экран кости закрывается как раньше; взятый зарок бой не играет) ([docs/realtime-casino.md](docs/realtime-casino.md), раздел «Срез казино-слоя в походе»).
- **Однорукий гоблин: «Перебор»** (в походе включено; в песочнице — флажок «„Перебор“: рискованные рывки» в группе «Однорукий гоблин»). С 12.10.2026 в походе гоблин приходит в каждый бой с ряда 1 (кроме Тюремщика и боссов) и даёт 6 рывков через 5 с. С 13.10.2026 (задача 11, «Гоблин-сюрприз») каждый гоблин похода при появлении бросает 0–3 безопасных рывка (по seed; игроку число не показано: у идола нет точек зарядов и подписи «безопасно», барабаны всех рывков крутят одну ленту без ☠, строка шансов на каждом рывке одна — «взрыв? −4 HP в круге · иначе тройка»; в прологе точек и подписи тоже нет; в комнате 8 с 15.10.2026 (задача 24 «Урок перебора») два рывка — верная тройка и показательный перебор с запалом 1,2 с, дверь открывается после взрыва); безопасный рывок — верная тройка доброго символа, без черепов (флажки песочницы «„Перебор“: безопасных рывков — случайно» и «Безопасный рывок — тройка»; в песочнице по умолчанию выключены — первые 3 рывка безопасны и крутят прежние барабаны). После безопасных — шанс взрыва 55 %; иначе — гарантированная тройка. Взрыв в походе с 13.10.2026 — по площади: идол горит 0,6 с (с 14.10.2026, задача 19 «Короткий запал»; было 1,2 с — так доигрывается поход, сохранённый раньше; пролог и песочница — 1,2 с), затем бьёт всех в круге 3,5 — герою 4 HP (спасают неуязвимость, прыжок и проход; щит цепи и щит фокуса — нет), врагам 3 (зачёт игроку); строка шансов говорит «−4 HP в круге». В песочнице без флажка «„Перебор“: взрыв по площади» — прежний удар герою сквозь любую защиту. Гоблин в походе приходит на 5-й секунде боя или через 3 с после целей — что раньше. На идоле — точки зарядов (золотые — безопасные, красные — с риском) и надпись «безопасно: N» или «взрыв 55 % · −4 HP в круге» (в песочнице без взрыва по площади — «взрыв 55 % · −4 HP») ([docs/realtime-casino.md](docs/realtime-casino.md), раздел «Перебор»). **Длинная цепь кормит гоблина** (в походе с 12.10.2026 до задачи 11, с 13.10.2026 выключено; в песочнице — ползунки «Длинная цепь» той же группы): каждая цепь, ударившая 6+ врагов за бой, до появления гоблина и после, даёт +1 безопасный рывок, но последний рывок всегда с риском (не больше 5 из 6); цепь 6+ в рычаг засчитывается до рывка — этот рывок без риска; над героем всплывает «+1 рывок без риска».
- **Щит фокуса** (в походе с 3-го вражеского звена; в песочнице — ползунок «Щит фокуса: со звена» в группе «Фокус», по умолчанию 0 — выключен). Пока цепь рисуется и фокус не пуст, касания и удары не ранят героя; вокруг него голубой ободок. Взрыв гоблина ранит и под щитом ([docs/realtime-prototype.md](docs/realtime-prototype.md), раздел 9с).
- **Смена цвета** (в походе всегда; в песочнице — ползунок «Смена цвета: после … звеньев» в группе «Кристаллы», по умолчанию 0 — выключено). После 6 вражеских звеньев одного цвета следующее звено может быть любого цвета, с него цвет и счёт начинаются заново. В походе свобода держится, пока цепь берёт тот же цвет (с 13.10.2026, `colorShiftKeep`; в песочнице — переключатель, по умолчанию выключен): 8 синих, затем красное — берётся; смены — на 6-м, 12-м, 18-м звене отрезка. В походе кристаллы не падают, ◆ гоблина остаются и тоже сбрасывают цвет. С 4-го звена цвета у указателя «до смены 2», затем «до смены 1»; 6-е звено получает радужное кольцо, тела всех цветов не приглушены. «Осколок жернова» — смена на 1 звено раньше, «Жернов» — на 2, «Призма» — +1 энергия за смену. Пока цвет свободен, тело другого цвета берётся только там, где мышь остановилась (или нажатием): быстрый мах через толпу и неподвижный курсор берут только цвет цепи (с 15.10.2026, задача 34, `shiftAtPointer`; поход и песочница — включено, панель «Цепь») ([docs/realtime-prototype.md](docs/realtime-prototype.md), раздел 9т).
- **Неуязвимость после цепи** — 0,5 с, золотое свечение героя (с 13.10.2026; касание в щит — искра «блок»). В походе — только за цепь, убившую 3 врага и больше (дизайн 12.10.2026); в песочнице — за 1 убийство (ползунок «Мин. убийств цепи для неуязвимости») ([docs/realtime-damage.md](docs/realtime-damage.md), раздел 4а).
- **Группа держится вместе** (в походе включено всегда; в песочнице — флажок «Группа держится вместе» в группе «Появление» панели отладки, по умолчанию выключен). Члену группы негде встать у якоря — он ждёт у того же якоря до 1 с, затем новый якорь получает вся оставшаяся группа ([docs/realtime-prototype.md](docs/realtime-prototype.md), раздел 9р).

Правила цепи, силы, фокуса, прохода, прыжка и кристаллов — [docs/realtime-prototype.md](docs/realtime-prototype.md).

Браузерные тесты (Playwright Chromium, `npx playwright install chromium`):

```sh
npm test                                   # то же, что npx playwright test
npx playwright test tests/realtime-run.spec.ts
```

Набор: песочница, враги, поход, расходники и талисманы, арены, местность, поведение, камера, петля, элиты, «Однорукий гоблин», ставка клятвы, кость у двери, глубина звена, второе дыхание, личный рекорд, журнал удачи, переброс талисманов, проклятый сундук, игорный круг гоблинов с живым «Колесом костей», экран конца похода («Незакрытое дело»), лечение на карте, подвиги и запись логов (`tests/realtime*.spec.ts`). Сервер Vite поднимается сам. Порт у каждой рабочей копии свой, 4620–5019, он вычисляется из пути копии (`PLAYWRIGHT_PORT` задаёт порт вручную): параллельные сессии не подхватывают чужой сервер. `RT_GPU=1` оставляет аппаратный GPU; по умолчанию программный рендер. Работает на Node 20 и 22. В полном тестировании прогон повторяют ×3 (`--repeat-each 3`). Известные нестабильные под нагрузкой тесты исправлены 12.10.2026 ([docs/realtime-slice.md](docs/realtime-slice.md), раздел 13): их ожидания короткого окна или игрового времени читают состояние в странице каждый кадр с пределом в игровых секундах (`tests/realtimeFrames.ts`), а «замороженная» сцена ставит и `maxEnemies` 0.

Полная проверка: `.claude/skills/verify-all/scripts/verify.sh [--browser]` (typecheck, все `test:*`, сборка, с `--browser` и Playwright). Её запускают в чистой копии, когда пользователь просит полное тестирование. В разработке достаточно быстрых проверок затронутого (`AGENTS.md`, раздел о проверках). Даты и результаты прогонов записывают в документ изменения. В старых записях встречаются проверки, которых больше нет (`test:golden` и другие проверки пошаговой игры): это история.

Детерминизм: одинаковые seed и журнал дают одинаковый хэш. Проверка — `npx tsx .claude/skills/determinism-check/scripts/determinism.ts`.

## Плейтест и логи

Игра пишет логи боёв и походов в браузер (кольцевой буфер в `localStorage`). Панель «Логи» (кнопка на экране похода) показывает записи; в ней кнопка «Копировать» кладёт JSON в буфер обмена. На dev-сервере запись идёт ещё и в `playtest-logs/` (папка в `.gitignore`). Формат и отчёт — [docs/realtime-telemetry.md](docs/realtime-telemetry.md), порядок сессий — [docs/realtime-playtest.md](docs/realtime-playtest.md).

## Инструменты разработки

Сборка страницы артефакта для плейтеста и её дымовые тесты — [tools/artifact/](tools/artifact/README.md).

Помощники Claude Code лежат в `.claude/agents/`, повторяемые процедуры — в `.claude/skills/`:

- `verify-all` — полная проверка (`verify.sh`);
- `determinism-check` — повтор журналов и свежих боёв, одинаковый хэш;
- `add-mechanic` — новое правило боя (параметр `Params`, хэш, журнал, документы);
- `author-level` — новая арена или состав;
- `docs-sync` — сверка документов с кодом (`doc-refs.sh`);
- `character-art`, `codex-delegate` — арт и делегирование Codex.
