# Сборка артефакта для плейтеста

Пользователь играет в прототип в артефакте claude.ai: https://claude.ai/artifact/Xu1g1ehswtttQBD9oGZRxX. Артефакт открыт всем, у кого есть ссылка (так задумано, решение пользователя 14.10.2026). Доступ меняют в меню Share на странице артефакта.
Страница артефакта — это `prototype.html` и `realtime.js` рядом с ней. Pixi.js загружается с CDN как глобальный `PIXI`.

## Когда собирать

После каждого push в `main`, если push меняет код игры. С 14.10.2026 основная ветка — `main` (до этого — `forest-biome-design`). Порядок такой:
1. Чистая сборка на ревизии push.
2. Дымовые тесты.
3. Публикация в тот же URL.
4. Отчёт пользователю.

LAN-сервер не запускайте, пока пользователь сам не попросит.

## Команды (Windows, macOS, Linux; нужны только Node и `npm ci` в репозитории)

```
git worktree add ../aa-artifact <rev>      # чистое дерево на ревизии push (или текущее, если оно чистое)
cd ../aa-artifact && npm ci                # своя node_modules; не ставьте зависимости через ссылку на общую
node tools/artifact/build.mjs              # → tools/artifact/out: realtime.js, realtime.css, prototype.html, local-test.html
node tools/artifact/smoke.mjs              # сервер 127.0.0.1:8799 + шесть проверок Playwright; снимки в out/shots
```

- `build.mjs` ставит номер сборки (`__RT_BUILD__`) по `git rev-parse --short HEAD`. На грязном дереве он предупреждает.
- `--no-telemetry` собирает страницу без канала телеметрии в базу артефакта.
- `ARTIFACT_OUT` задаёт другой каталог вывода.

## Дымовые тесты (`checks/`)

Каждая проверка печатает одну строку JSON. Пустой `errs` — ошибок страницы нет.

| Файл | Что проверяет |
|---|---|
| `prologue.mjs` | Первый запуск открывает пролог «1/10 · Тропа». Настоящая цепь убивает трёх врагов. «Пропустить» ведёт к походу и запоминает ключ. |
| `run5.mjs` | Новый поход, дар, первый бой: 6 цепей, статус `playing`, HP и убийства. |
| `cam.mjs`, `archer.mjs`, `col.mjs` | Песочница: камера на большой арене, лучник, подписи сборки. |
| `purse.mjs` | Строка очков в HUD боя. |

`smoke.mjs` возвращает код 1, если проверка упала или у неё непустой `errs`. Числа (HP, время) зависят от seed и ревизии. Сравнивайте их с прошлой сборкой, а не с жёстким порогом.
